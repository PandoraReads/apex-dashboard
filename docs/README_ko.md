## 기능

### 🗒️ 메모 (Memo)
내장 메모장으로 생각을 즉시 기록하세요. 각 메모 카드에는 입력 가능한 텍스트 영역이 있어, 대시보드를 떠나지 않고도 아이디어, 회의록, 하루의 기록을 적을 수 있습니다. 클릭 가능한 링크로 렌더링되는 `[[위키링크]]`를 지원합니다.

### ✅ 할 일 (Todo)
인터랙티브 체크리스트로 작업을 관리하세요. 작업을 추가하고, 순서를 바꾸고, 드래그 앤 드롭하고, 체크할 수 있습니다. 진행률 표시줄로 완료율을 한눈에 확인할 수 있습니다. 할 일 항목에서도 노트를 상호 참조할 수 있도록 `[[위키링크]]`를 지원합니다.

### 📁 프로젝트 (Projects)
볼트 문서를 프로젝트 카드로 정리하세요. 각 카드는 관련 노트로 연결되고, 커버 이미지(볼트 내 로컬 이미지와 웹 URL 모두 지원)를 표시하며, 새 파일을 빠르게 추가할 수 있는 인라인 문서 검색을 지원합니다. Markdown 노트, PDF, 이미지, 오디오, 비디오 등 다양한 파일 형식을 관리할 수 있습니다.

### 📝 노트 (Notes)
참고 문서와 자주 쓰는 파일을 정리하는 컴팩트한 목록형 섹션입니다. 최대 밀도를 위해 커버 이미지 없이 한 줄에 최대 5개의 카드를 표시합니다.

### 📅 캘린더
볼트 전체의 날짜가 지정된 모든 작업을 보여주는 네이티브 월간 그리드 캘린더입니다 (dataview나 외부 플러그인이 필요 없습니다). 각 날짜 셀에는 해당 날의 작업이 나열되고, 날짜를 클릭하면 그날의 일정을 볼 수 있습니다. 월 단위 탐색과 인라인 토글이 가능한 전체 화면 캘린더를 열 수 있습니다. `[start::]` / `[end::]`가 있는 여러 날에 걸친 이벤트는 여러 날에 걸쳐 표시됩니다. 사이드바 위젯의 확대 보기는 보드에 삽입되는 **캘린더 섹션**으로도 사용할 수 있습니다 — 전체 월간 그리드(여러 날 바 포함), 주간 시간 그리드, 작업 필터, 오늘로 이동 기능이 있으며, 날짜 숫자를 클릭하면 그날의 작업을 추가할 수 있습니다(데일리 노트 또는 대시보드 할 일 목록에 기록됩니다).

### 🔍 Dataview
내장 DQL 엔진으로 볼트를 쿼리하세요 — Dataview 플러그인이 필요 없습니다. Dataview 섹션을 추가하고 `TABLE file.name, rating FROM "Books" WHERE rating >= 4 SORT rating DESC` 같은 쿼리를 작성하세요. `FROM`(폴더, 태그, 링크)으로 대상을 지정하고, `WHERE`, `SORT`, `GROUP BY`, `FLATTEN`, `LIMIT` 절과 함께 `TABLE`, `LIST`, `TASK`, `CALENDAR`, `HEATMAP` 출력을 지원하며, 약 40개의 내장 함수, 모든 `file.*` 암시적 필드, YAML frontmatter, 인라인 필드(`[key:: value]`)를 사용할 수 있습니다. 설정 모달은 실시간으로 문법을 검증하고 원클릭 샘플 쿼리를 제공합니다. `TASK` 체크박스는 원본 노트에 다시 기록되고, `CALENDAR`는 월간 그리드를 그리며, `HEATMAP`은 임의의 숫자 필드로 1년 기여 그리드를 그립니다. 결과는 섹션의 새로고침 버튼으로 필요할 때 갱신됩니다.

### 🌐 웹 (Web)
어떤 웹 페이지든 섹션에 바로 임베드하세요 — URL을 붙여넣으면 보드 안의 브라우저 창처럼 탐색할 수 있습니다. **자동 모드**는 사이트의 프레이밍 정책을 미리 확인합니다: 프레임 허용 사이트는 iframe으로 바로 임베드되고, 거부하는 사이트는 데스크톱 webview로 전환됩니다(별도의 지속적인 로그인 유지 — Keep, Todoist 웹 등 로그인 앱에 권장). 모바일에서는 브라우저에서 열기 버튼이 있는 대체 카드를 표시합니다. iframe/webview 모드를 강제로 지정할 수도 있고, 밀도 높은 웹 앱을 위해 페이지를 0.5–2배로 확대/축소할 수도 있습니다. 모바일에서는 https 사이트를 권장하며, 임베딩은 읽기 중심입니다 — 팝업과 다운로드는 실제 브라우저에서 처리하세요.

### 📡 RSS
블로그와 뉴스 피드를 보드에서 바로 구독하세요: RSS 2.0 / Atom 링크를 추가하면 모든 피드의 최신 글이 하나의 역시간순 목록으로 모입니다(출처 태그, 읽지 않음 표시). 읽지 않음 필터와 모두 읽음으로 표시 기능이 있습니다. 항목을 클릭하면 모달에서 전체 글을 읽을 수 있습니다 — 전문을 제공하는 피드는 바로 렌더링되고, 요약만 제공하는 피드는 자동으로 가져와서 본문을 추출합니다. 모든 항목에는 글을 볼트 노트로 저장하는 다운로드 버튼이 있어(날짜 접두사 이름, 출처 frontmatter, 원본 링크) 설정된 폴더에 저장되며, 저장된 항목은 해당 노트로 바로 이동합니다. 피드 콘텐츠는 30분간 로컬에 캐시되고, 읽음 및 저장 상태는 세션 간에 유지됩니다.

### ⚡ 빠른 작업 (Quick Actions)
가장 자주 쓰는 바로가기를 사이드바에 고정하세요. 두 가지 작업 유형을 지원합니다: 문서를 여는 **파일** 링크와, 어떤 Obsidian 명령이든 실행하는 **명령** 바로가기. 새 일기와 새 노트용 내장 프리셋이 포함되어 있습니다.

### 🌤️ 사이드바 위젯
왼쪽 사이드바에는 독립적으로 켜고 끌 수 있고 드래그로 순서를 바꿀 수 있는 11개의 위젯이 있습니다:

- **날씨** — 현재 기온, 체감 온도, 습도, 풍속과 일별 최고/최저 기온이 포함된 5일 예보를 제공하는 실시간 날씨. Open-Meteo 기반(API 키 불필요). 정확한 위치를 위한 지오코딩 자동완성 도시 검색
- **음력 만세력** — 전통 중국 음력 날짜, 명절, 일일 행운/금기 안내
- **뽀모도로 타이머** — 활동 선택과 집중/휴식 사이클이 있는 집중 타이머, 오늘의 비율을 보여주는 도넛 차트. 통계 보기에는 목표 진행률, 효율 점수, 추이 차트, 12주 히트맵, 오늘 타임라인이 추가됩니다
- **독서 트래커** — 내장 타이머로 독서 세션을 기록하세요. Douban 검색이나 직접 입력으로 책을 추가하고, 독서 시간을 측정하며, 페이지 번호로 진행 상황을 기록합니다. 각 책 카드는 커버 이미지, 저자, 독서 진행률 표시줄을 보여줍니다
- **카운트다운** — 원하는 목표 날짜까지의 카운트다운을 사용자 지정하여 남은 일수 또는 시간으로 표시
- **연간 진행률** — 올해가 얼마나 지났는지 표시
- **캘린더** — 볼트 전체의 날짜가 지정된 모든 작업을 모으는 월간/주간 그리드. 날짜를 클릭하면 그날의 일정을 보고 작업을 추가할 수 있으며, 그날의 데일리 노트에 기록됩니다. 여러 날에 걸친 이벤트는 여러 날에 걸쳐 표시됩니다
- **습관 체크인** — 습관별 매일 체크, 전날 소급 체크, 연속 기록과 히트맵 통계
- **가계부** — 빠른 지출/수입 입력(메모, 과거 날짜 입력, 사용자 지정 카테고리)과 오늘 합계 및 주/월/연/전체 통계. 장부에는 필터링, 인라인 편집, CSV 가져오기/내보내기가 추가됩니다
- **포토 앨범** — 볼트 폴더를 위한 디지털 포토 프레임: 마우스를 올리면 일시정지되는 자동 회전, 수동 이전/다음 버튼과 인덱스 배지, 1:1 또는 3:4 패널 비율, 네 가지 전환 효과(페이드 / 왼쪽 밀기 / 오른쪽 밀기 / 줌), 3–60초 간격, 기본적으로 하위 폴더 포함. 첫 사진은 시간 기반으로 선택되어(항상 같은 사진이 아님) 다음 사진은 미리 로드되고, 볼트에서 추가/삭제/이름 변경이 발생하면 위치를 잃지 않고 목록이 바로 갱신됩니다
- **음악** — 사이드바에서 NetEase Cloud Music 무료 트랙을 검색하고 재생합니다: 설정에서 NetEase 계정 로그인(옵션)으로 계정 권한이 있는 멤버십 트랙 재생, 플레이리스트 링크 붙여넣기 가져오기, 볼륨 및 반복 컨트롤, 느린 커버 백필이 있는 영구 플레이리스트, 그리고 대시보드를 닫아도 계속 작동하는 선택적 플로팅 미니 플레이어 바(데스크톱 전용)

사이드바에는 **주간 캘린더 스트립**(7일 컴팩트 표시, 오늘 강조), **최근 문서**, **맨 위로** 버튼도 있습니다. 휴대폰에서도 동일한 위젯 바를 사용하며, 위젯 데이터는 기기 간에 합집합으로 병합됩니다.

### 🎨 배너 (Banner)
영감을 주는 명언과 선택적 배경 이미지가 있는 사용자 지정 가능한 배너입니다. 볼트 내 로컬 이미지와 웹 URL을 모두 지원합니다. 더블클릭하여 편집하세요.

### 🔄 드래그 앤 드롭
카드를 섹션 사이로 드래그하여 작업 공간을 재구성하세요. 할 일 카드 안에서 작업 항목을 드래그하여 순서를 바꿀 수 있습니다. 프로젝트/노트 카드 사이에서 문서 링크를 드래그할 수 있습니다.

### 🧩 사용자 지정 섹션
**15가지 섹션 유형**을 자유롭게 조합하세요 — **Todo**, **메모(Memo)**, **스티키 노트(Sticky Notes)**, **노트(프로젝트 카드)**, **노트(커버 없음)**, **Dataview**, **라이브러리(Library)**, **폴더(Folder)**, **이미지(Images)**, **비디오(Videos)**, **캘린더(Calendar)**, **Weread**, **TickTick**, **웹(Web)**, **RSS** — 각각 고유한 레이아웃과 동작이 있어 보드를 여러분의 워크플로우에 맞출 수 있습니다.

### 🕐 최근 문서
사이드바에 상대 시간 표시와 함께 최근 편집한 파일을 보여주어, 마지막 작업으로 바로 돌아갈 수 있습니다.

## 설정

- **대시보드 파일** — 대시보드 데이터 파일 경로를 사용자 지정
- **스타일** — 13가지 비주얼 테마 중 선택
- **언어** — 영어 또는 중국어 인터페이스
- **최근 문서 개수** — 표시할 최근 파일 수 조절
- **사이드바 위젯** — 날씨, 히트맵, 뽀모도로, 독서, 카운트다운. 각 위젯을 독립적으로 활성화/비활성화하고 구성
- **독서 설정** — 독서 트래커 토글, 세션 완료 사운드 활성화/비활성화

## 설치

### Obsidian 커뮤니티 플러그인에서
1. 설정 > 커뮤니티 플러그인 열기
2. 찾아보기에서 "Apex Dashboard" 검색
3. 설치를 클릭한 후 활성화

### 수동 설치
1. [GitHub Releases](https://github.com/pandorareads/apex-dashboard/releases)에서 최신 릴리스 다운로드
2. 볼트의 `.obsidian/plugins/apex-dashboard/` 폴더에 압축 해제
3. 설정 > 커뮤니티 플러그인에서 "Apex Dashboard" 활성화

## 사용법

- **캘린더 주간 뷰** — Calendar 섹션에 새로운 월 | 주 토글. 컬럼 내 주간 뷰는 컴팩트한 세로 목록이고(시간순 정렬, 시간 라벨 포함), 전체 화면 모달의 주간 뷰는 구글 캘린더 스타일의 시간 그리드입니다(시간 축 + 7일 컬럼, 시간에 따라 작업 배치/크기 조절, 종일 스트립, "지금" 선). 시간은 `⏰` 리마인더와 `HH:MM` 형식의 `[due::]`/`[start::]`/`[end::]`에서 옵니다
- **캘린더에서 작업 추가** — 날짜 클릭 → 그날의 일정에서 (선택적 시간이 있는) 작업을 추가하면 그날의 데일리 노트(Daily Notes 템플릿/경로에서 자동 생성)에 기록됩니다; `⏰`로 시간을, `📅`로 날짜만 표시합니다

- **성능 및 모바일 수정** — 비디오 썸네일이 더 이상 미디어 디코더를 누수하지 않습니다(무한 메모리 증가 + 휴대폰 과열/동결 수정); 모바일에서는 정적 플레이스홀더를 렌더링합니다. 노트를 편집하면 보드 전체를 재구축하는 대신 영향을 받은 섹션만 그 자리에서 새로 고칩니다(더 이상 "비디오 라이브러리가 계속 새로고침"되지 않습니다)
- **지연 로딩 비디오(데스크톱) + 더 빠른 스캔 + 모바일 GPU** — 화면에 보이는 타일만 실제 `<video>`를 마운트합니다(IntersectionObserver); 볼트 작업 스캔(Calendar)은 작업 없는 파일을 건너뛰고 UI에 양보합니다; 모바일(≤640px)에서는 카드별 유리 블러가 비활성화되어 GPU 부하와 발열을 줄입니다

- **중첩 작업 (서브태스크)** — 작업이 이제 들여쓰기된 Markdown으로 저장되는 다단계 중첩을 지원합니다. 작업을 다른 위로 드래그해 중첩하고(이전 / 이후 / 중첩 드롭 영역), 작업을 재정렬하거나, 카드 간에 이동하세요. 모바일에서는 길게 눌러 드래그하고, 수평으로 스와이프해 중첩/해제합니다. 부모 작업을 체크하면 모든 자식이 체크됩니다

데스크톱에서 설정 → Apex Dashboard → 위젯 → 음악을 열고 휴대폰 / NetEase 로그인을 선택하세요. 제공되는 경우 공식 사이트에서 휴대폰 로그인을 완료하세요; NetEase는 QR 로그인을 요구할 수 있습니다. 이 플러그인에는 별도의 SMS 엔드포인트가 없습니다. 멤버십, 구매, 지역 권한은 NetEase가 확인합니다; 체험 클립은 전체 트랙으로 재생되지 않습니다.

자격 증명은 NetEase로 직접 제출됩니다. 플러그인은 계정 및 재생 URL 요청에 로컬 세션을 사용합니다. 쿠키는 data.json과 볼트 동기화 밖의 격리된 로컬 Obsidian Electron 세션에 유지됩니다. 로그아웃하면 재생이 중지되고 해당 로컬 세션이 삭제됩니다. 만료되면 다시 로그인하세요. 서드파티 프록시는 사용되지 않습니다.

### 섹션 간 카드 이동

카드 헤더를 드래그하여 Todo, Memo, Sticky 섹션 사이로 옮기세요. 커버가 있거나 없는 노트도 이 섹션들로 이동할 수 있습니다. Memo 목적지는 원본 텍스트, 작업, 링크를 메모로 표시합니다. Todo 목적지는 기존 작업을 유지하고, 다른 비어 있지 않은 텍스트 줄과 노트 링크를 체크되지 않은 항목으로 바꿉니다. Sticky 목적지는 노트에 커버가 있는지 여부를 포함해 원본 카드 모양을 유지합니다. 변경 사항은 다시 로드해도 유지됩니다. 보드 카드를 이동해도 링크된 볼트 파일은 이동하거나 삭제되지 않습니다.

## ฟีเจอร์

### 🗒️ Memo
จดความคิดได้ทันทีด้วยแผ่นจดบันทึก (memo pad) ที่มีในตัว การ์ด memo แต่ละใบมีช่อง textarea ที่พิมพ์ได้ — จดไอเดีย โน้ตประชุม หรือบันทึกประจำวันได้โดยไม่ต้องออกจากแดชบอร์ด รองรับ `[[wikilinks]]` ที่แสดงผลเป็นลิงก์คลิกได้

### ✅ Todo
จัดการงานด้วยเช็กลิสต์แบบอินเทอร์แอกทีฟ เพิ่ม จัดลำดับใหม่ ลากวาง และติ๊กทำเสร็จ แถบความคืบหน้าแสดงเปอร์เซ็นต์ความเสร็จได้ในแวบเดียว รายการ Todo ยังรองรับ `[[wikilinks]]` สำหรับอ้างอิงโน้ตข้ามกัน

### 📁 Projects
จัดระเบียบเอกสารใน vault ของคุณเป็นการ์ดโปรเจกต์ การ์ดแต่ละใบลิงก์ไปยังโน้ตที่เกี่ยวข้อง แสดงภาพปก (รองรับทั้งรูปใน vault และ URL จากเว็บ) และรองรับการค้นหาเอกสารแบบ inline เพื่อเพิ่มไฟล์ใหม่ได้อย่างรวดเร็ว จัดการไฟล์ได้หลายประเภท ทั้งโน้ต Markdown, PDF, รูปภาพ, เสียง และวิดีโอ

### 📝 Notes
ส่วนแบบรายการที่กะทัดรัดสำหรับจัดระเบียบเอกสารอ้างอิงและไฟล์ที่ต้องเข้าถึงบ่อย แสดงได้ถึง 5 การ์ดต่อแถวโดยไม่มีภาพปก เพื่อความหนาแน่นสูงสุด

### 📅 Calendar
ปฏิทินตารางเดือนแบบเนทีฟของทุกงานที่มีวันที่ใน vault ของคุณ (ไม่ต้องใช้ dataview หรือปลั๊กอินภายนอก) แต่ละช่องวันจะแสดงรายการงานของวันนั้น คลิกที่วันเพื่อดูกำหนดการของวันนั้น เปิดปฏิทินแบบเต็มจอพร้อมการเลื่อนเดือนและการสลับสถานะแบบ inline ได้ เหตุการณ์หลายวันที่มี `[start::]` / `[end::]` จะคร่อมคาบหลายวัน มุมมองขยายของวิดเจ็ตในแถบข้างยังพร้อมใช้งานเป็น **ส่วน Calendar** ที่ฝังอยู่ในบอร์ดด้วย — ตารางเดือนเต็ม (พร้อมแถบเหตุการณ์หลายวัน), ตารางเวลารายสัปดาห์, ตัวกรองงาน และปุ่มกลับมาวันนี้ คลิกเลขวันที่เพื่อเพิ่มงานสำหรับวันนั้น (เขียนลง daily note หรือรายการ todo ของแดชบอร์ด)

### 🔍 Dataview
สอบถามข้อมูลใน vault ของคุณด้วยเอนจิน DQL ที่มีในตัว — ไม่ต้องติดตั้งปลั๊กอิน Dataview เพิ่มส่วน Dataview แล้วเขียนคำสั่งค้นหาอย่างเช่น `TABLE file.name, rating FROM "Books" WHERE rating >= 4 SORT rating DESC` รองรับผลลัพธ์แบบ `TABLE`, `LIST`, `TASK`, `CALENDAR` และ `HEATMAP` บนโฟลเดอร์ แท็ก และลิงก์ (`FROM`) พร้อมประโยค `WHERE`, `SORT`, `GROUP BY`, `FLATTEN` และ `LIMIT` ฟังก์ชันในตัวราว 40 ตัว ฟิลด์ implicit ทั้งหมดแบบ `file.*`, YAML frontmatter และฟิลด์ inline (`[key:: value]`) หน้าต่างตั้งค่าตรวจสอบไวยากรณ์แบบสด ๆ และมาพร้อมคำสั่งค้นหาตัวอย่างที่คลิกเดียวได้ เช็กบ็อกซ์ของ `TASK` จะเขียนกลับไปยังโน้ตต้นทาง `CALENDAR` วาดตารางเดือน และ `HEATMAP` วาดตารางคอนทริบิวชันรายปีจากฟิลด์ตัวเลขใดก็ได้ ผลลัพธ์รีเฟรชตามต้องการผ่านปุ่มรีเฟรชของส่วนนั้น

### 🌐 Web
ฝังหน้าเว็บใดก็ได้ลงในส่วนหนึ่งโดยตรง — วาง URL แล้วใช้งานเหมือนแผงเบราว์เซอร์ในบอร์ด โหมด **Auto** จะตรวจสอบนโยบายการฝัง (framing policy) ของเว็บไซต์ก่อน: เว็บที่ฝังได้จะแสดงเป็น iframe โดยตรง ส่วนเว็บที่ปฏิเสธจะสลับไปใช้ webview แบบเดสก์ท็อป (มีระบบล็อกอินแบบคงอยู่ของตัวเอง — แนะนำสำหรับ Keep, Todoist เว็บ และแอปที่ต้องล็อกอินอื่น ๆ) บนมือถือจะแสดงการ์ดสำรองพร้อมปุ่มเปิดในเบราว์เซอร์ คุณยังสามารถบังคับโหมด iframe/webview และปรับสเกลหน้าเว็บ 0.5–2 เท่าสำหรับเว็บแอปที่ข้อมูลแน่น ควรใช้เว็บ https บนมือถือ การฝังนี้เน้นการอ่าน — ป๊อปอัปและการดาวน์โหลดควรทำในเบราว์เซอร์จริง

### 📡 RSS
ติดตามบล็อกและฟีดข่าวได้บนบอร์ดโดยตรง: เพิ่มลิงก์ RSS 2.0 / Atom ใดก็ได้ แล้วบทความล่าสุดจากทุกฟีดจะไหลรวมกันในรายการเรียงจากใหม่ไปเก่า (แท็กแหล่งที่มา จุดแสดงยังไม่อ่าน) พร้อมตัวกรองยังไม่อ่านและปุ่มทำเครื่องหมายว่าอ่านหมดแล้ว คลิกบทความเพื่ออ่านเต็มในหน้าต่าง modal — ฟีดที่มีเนื้อหาเต็มจะแสดงโดยตรง ส่วนฟีดที่ให้เฉพาะสรุปจะถูกดึงและแยกเนื้อหาหลักให้อัตโนมัติ ทุกบทความมีปุ่มดาวน์โหลดที่บันทึกบทความเป็นโน้ตใน vault (ชื่อขึ้นต้นด้วยวันที่ frontmatter แหล่งที่มา ลิงก์ต้นฉบับ) ลงในโฟลเดอร์ที่ตั้งค่าไว้ รายการที่บันทึกแล้วจะพาคุณไปยังโน้ตนั้นทันที เนื้อหาฟีดถูกแคชไว้ในเครื่อง 30 นาที สถานะการอ่านและการบันทึกคงอยู่ข้ามเซสชัน

### ⚡ Quick Actions
ปักหมุดทางลัดที่คุณใช้บ่อยที่สุดไว้ในแถบข้าง รองรับสองประเภท: **File** สำหรับลิงก์เปิดเอกสารใดก็ได้ และ **Command** สำหรับทางลัดเรียกคำสั่ง Obsidian ใดก็ได้ มีพรีเซ็ตในตัวสำหรับ New Journal และ New Note

### 🌤️ Sidebar Widgets
แถบข้างซ้ายมีวิดเจ็ต 11 ตัวที่เปิด/ปิดได้อิสระและลากจัดลำดับใหม่ได้:

- **Weather** — สภาพอากาศแบบเรียลไทม์ พร้อมอุณหภูมิปัจจุบัน อุณหภูมิที่รู้สึกได้ ความชื้น ความเร็วลม และพยากรณ์ 5 วันพร้อมอุณหภูมิสูงสุด/ต่ำสุดรายวัน ขับเคลื่อนด้วย Open-Meteo (ไม่ต้องใช้ API key) ค้นหาเมืองพร้อมระบบเติมข้อความอัตโนมัติจาก geocoding เพื่อความแม่นยำของตำแหน่ง
- **Lunar Almanac** — วันที่จันทรคติจีนแบบดั้งเดิม เทศกาล และคำแนะนำสิ่งที่ควรทำ/ไม่ควรทำประจำวัน
- **Pomodoro Timer** — ตัวจับเวลาโฟกัสพร้อมตัวเลือกกิจกรรมและวงจรทำงาน/พัก พร้อมโดนัทชาร์ตแสดงสัดส่วนของวันนี้ มุมมองสถิติเพิ่มความคืบหน้าของเป้าหมาย คะแนนประสิทธิภาพ กราฟแนวโน้ม ฮีตแมป 12 สัปดาห์ และไทม์ไลน์ของวันนี้
- **Reading Tracker** — ติดตามเซสชันการอ่านด้วยตัวจับเวลาในตัว เพิ่มหนังสือจากการค้นหา Douban หรือกรอกเอง จับเวลาการอ่าน และบันทึกความคืบหน้าพร้อมเลขหน้า การ์ดหนังสือแต่ละเล่มแสดงภาพปก ผู้แต่ง และแถบความคืบหน้าการอ่าน
- **Countdown** — ตัวนับถอยหลังที่ปรับแต่งได้สำหรับวันเป้าหมายใดก็ได้ แสดงเป็นจำนวนวันหรือชั่วโมงที่เหลือ
- **Year Progress** — ปีปัจจุบันผ่านไปแล้วเท่าไร
- **Calendar** — ตารางเดือน/สัปดาห์ที่รวมทุกงานที่มีวันที่ใน vault คลิกวันเพื่อดูกำหนดการและเพิ่มงานที่เขียนลง daily note ของวันนั้น เหตุการณ์หลายวันคร่อมคาบหลายวันได้
- **Habit Check-in** — ติ๊กเช็กอินรายวันต่อหนึ่งนิสัย พร้อมการเติมย้อนหลังของเมื่อวาน streak และสถิติฮีตแมป
- **Expense Tracker** — บันทึกรายรับ/รายจ่ายอย่างรวดเร็ว (มีโน้ต, บันทึกย้อนวัน, หมวดหมู่แบบกำหนดเอง) พร้อมยอดรวมวันนี้และสถิติแบบสัปดาห์/เดือน/ปี/ตลอดกาล บัญชีรายวันเพิ่มการกรอง การแก้ไข inline และนำเข้า/ส่งออก CSV
- **Photo Album** — กรอบภาพดิจิทัลสำหรับโฟลเดอร์ใดก็ได้ใน vault: หมุนเวียนอัตโนมัติพร้อมหยุดเมื่อชี้เมาส์ เลื่อนก่อนหน้า/ถัดไปด้วยมือและป้ายดัชนี สัดส่วนแผง 1:1 หรือ 3:4 เอฟเฟกต์เปลี่ยนภาพสี่แบบ (fade / push left / push right / zoom) ช่วงเวลา 3–60 วินาที รวมโฟลเดอร์ย่อยโดยค่าเริ่มต้น ภาพแรกเมื่อเปิดถูกกำหนดจากเวลา (ไม่ใช่ภาพเดิมเสมอ) ภาพถัดไปถูกโหลดล่วงหน้า และการเพิ่ม/ลบ/เปลี่ยนชื่อไฟล์ใน vault จะรีเฟรชรายการในที่เดิมโดยไม่หลุดตำแหน่งของคุณ
- **Music** — ค้นหาและเล่นเพลงจาก NetEase Cloud Music รุ่นฟรีจากแถบข้าง: ล็อกอินบัญชี NetEase ได้ตามต้องการในหน้าตั้งค่าเพื่อเข้าถึงเพลงสมาชิกตามสิทธิ์บัญชี วางลิงก์เพลย์ลิสต์เพื่อนำเข้า ปุ่มปรับเสียงและเล่นซ้ำ เพลย์ลิสต์ที่บันทึกถาวรพร้อมการเติมปกแบบ lazy และแถบมินิเพลเยอร์แบบลอยที่ยังทำงานต่อได้แม้ปิดแดชบอร์ด (เฉพาะเดสก์ท็อป)

แถบข้างยังมี **แถบปฏิทินรายสัปดาห์** (7 วันแบบกระชับ เน้นวันนี้), **เอกสารล่าสุด** และปุ่ม **เลื่อนขึ้นบนสุด** โทรศัพท์ก็มีแถบวิดเจ็ตแบบเดียวกัน และข้อมูลวิดเจ็ตจะรวมแบบ union ข้ามอุปกรณ์

### 🎨 Banner
แบนเนอร์ปรับแต่งได้พร้อมคำคมสร้างแรงบันดาลใจและภาพพื้นหลังเสริม รองรับทั้งรูปใน vault และ URL จากเว็บ ดับเบิลคลิกเพื่อแก้ไข

### 🔄 Drag & Drop
ลากการ์ดระหว่างส่วนเพื่อจัดระเบียบพื้นที่ทำงานใหม่ ลากรายการงานภายในการ์ด Todo เพื่อจัดลำดับ ลากลิงก์เอกสารระหว่างการ์ดโปรเจกต์/โน้ต

### 🧩 Custom Sections
**ประเภทส่วน 15 แบบ** ให้ผสมผสานกันได้ — **Todo**, **Memo**, **Sticky Notes**, **Notes (project cards)**, **Notes (no cover)**, **Dataview**, **Library**, **Folder**, **Images**, **Videos**, **Calendar**, **Weread**, **TickTick**, **Web** และ **RSS** — แต่ละแบบมีเลย์เอาต์และพฤติกรรมเป็นของตัวเอง เพื่อให้บอร์ดเข้ากับ workflow ของคุณ

### 🕐 Recent Documents
แถบข้างแสดงไฟล์ที่แก้ไขล่าสุดพร้อมเวลาแบบเปรียบเทียบ เพื่อให้คุณกลับเข้าสู่งานล่าสุดได้ทันที

## มีอะไรใหม่

### 3.9.2
- **สลับธีมทันทีในคลังสื่อ** — ตอนนี้หน้าคลังสื่อจะปรับธีมใหม่แบบในที่ทันทีที่คุณสลับธีมของปลั๊กอิน เหมือนกับบอร์ดของแดชบอร์ดทุกประการ ไม่ต้องปิดแล้วเปิดใหม่; สีที่กำหนดเอง ภาพพื้นหลัง และการตั้งค่ารูปลักษณ์ก็มีผลกับหน้าคลังสื่อด้วยแล้ว
- **ตัวกรองประเภทยุบรวมเป็น dropdown เดียว** — ตัวกรองรูปภาพ/วิดีโอ/ข้อความกลายเป็นปุ่ม dropdown เดียวเพื่อให้แถบเครื่องมือเรียบง่ายขึ้น และการแบ่งหน้าเปลี่ยนเป็นแบบราบ ทุกสื่อยังคงเข้าถึงได้โดยตรง
- **ชุดสีแถบฐานการ์ดชุดใหม่** — แถบเมทาดาต้าด้านล่างของการ์ดโพลารอยด์ตอนนี้ใช้ชุดสีที่คัดสรรมาอย่างพิถีพิถัน ใช้ร่วมกันทั้งโหมดสว่างและมืด

### 3.9.1
- **ปลดเพดาน 500 รายการของคลังสื่อ** — เดิมการเรนเดอร์แต่ละครั้งตัดแบบหยาบที่ 500 รายการ สื่อที่เกินมาเลื่อนดูไม่ถึง และในมุมมองแบบกลุ่มจะทำให้โฟลเดอร์ทั้งกลุ่มหายไปด้วย; ตอนนี้เปลี่ยนเป็น: มุมมองเรียงตรงแบ่งหน้าเข้าถึงสื่อทั้งหมดได้, มุมมองแบบกลุ่มเรนเดอร์แบบก้าวหน้าทีละกลุ่ม (ชุดแรก 50 รายการ + ปุ่ม «แสดงเพิ่มเติม»), กลุ่มที่พับอยู่จะไม่สร้างเนื้อหาเลย — vault ขนาดมหึมาไม่สูญเสียสื่อ และไม่ต้องเมาน์โหนดหมื่นกว่าตัวในครั้งเดียว
- **ลากย้ายในมุมมองแบบกลุ่มโฟลเดอร์** — ในมุมมองแบบกลุ่มโฟลเดอร์ ลากการ์ดสื่อไปวางอีกกลุ่มหนึ่งเพื่อย้ายไฟล์: เลือกหลายรายการลากพร้อมกันเพื่อย้ายแบบกลุ่ม ชื่อซ้ำจะถูกข้ามพร้อมแจ้งเตือน และเมื่อชี้ค้างเหนือกลุ่มเป้าหมายจะแสดง «ปล่อยเพื่อย้ายไปยัง ××»
- **แก้ไขเลย์เอาต์คอลัมน์ของกลุ่ม** — หลังจากตรวจสอบอัตราส่วนภาพเสร็จ ทุกกลุ่มจะจัดเรียงคอลัมน์แบบ masonry ใหม่ (เดิมมีเพียงกลุ่มแรกเท่านั้นที่จัดเรียงใหม่)

### 3.9.0
- **คลังสื่อใหม่ทั้งหมด** — เพิ่มไอคอน square-sparkles บนแถบฟังก์ชันด้านซ้าย เพื่อเปิดคลังสื่อเต็มหน้า: รูปภาพ วิดีโอ และโน้ตที่มีปกใน vault รวมเป็น masonry stream เดียว
- **การ์ดสองสไตล์** — สลับระหว่างการ์ดปกเดิม / การ์ดโพลารอยด์สไตล์ Pin ได้ในคลิกเดียว มีความหนาแน่นสามระดับ เรียกดูแยกตามโฟลเดอร์ แท็ก หรือประเภท; มุมมองแบบกลุ่มมีแถบนำทางด้านซ้ายและพับทั้งหมดในคลิกเดียว
- **คอลเลกชันโปรด** — กดหัวใจบนการ์ดเพื่อเก็บสื่อลงโปรด ปุ่มหัวใจบนแถบเครื่องมือช่วยดูเฉพาะรายการโปรดในคลิกเดียว
- **จัดระเบียบแบบกลุ่ม** — ลากกรอบเพื่อเลือกหลายรายการ แถบไอคอนฟังก์ชันด้านขวาช่วยติดแท็ก ย้าย คัดลอกพาธ และลบแบบกลุ่ม
- **เชื่อมต่อ Agent** — ส่งสื่อที่เลือกไปยังสกิล Agent ในคลิกเดียว พาธถูกใส่เข้าเทมเพลตพรอมต์โดยอัตโนมัติ
- **ลากเข้าเพื่อบันทึก** — ลากรูปภาพ/วิดีโอจากที่ไหนก็ได้ในคอมพิวเตอร์ ระบบจะคัดลอกเข้า vault วางตำแหน่งตามกลุ่ม และติดแท็กให้โดยอัตโนมัติ; ตำแหน่งจัดเก็บเริ่มต้นปรับได้ในการตั้งค่า

### 3.8.11
- **ขยายอินเทอร์เฟซหลายภาษา** — เพิ่มภาษาญี่ปุ่น เกาหลี สเปน ฝรั่งเศส เยอรมัน โปรตุเกส (บราซิล) รัสเศษ และไทย รวมกับภาษาจีนตัวย่อ จีนตัวเต็ม และอังกฤษ รองรับอินเทอร์เฟซรวม 11 ภาษา; การติดตั้งใหม่สามารถตามภาษาของ Obsidian หรือสลับผ่านการตั้งค่าหรือรายการเลือกภาษา คำแปลบรรจุมาแบบออฟไลน์
- **รูปลักษณ์พื้นที่ทำงานแบบ immersive** — ภาพพื้นหลังตั้งค่าแยกจากพื้นที่ทำงานปกติได้ และปรับแต่งฟอนต์กับสีของนาฬิกาด้านบนได้; ทางเข้าการแก้ไขถูกรวบอยู่ใต้ปุ่มแก้ไขเลย์เอาต์
- **โหมดนับจำนวนของนิสัย** — นิสัยสลับเป็นการคลิกซ้ำเพื่อสะสมจำนวนได้ วิดเจ็ตแสดงจำนวนของวันนั้น และแผงสถิติรองรับดูข้อมูลสะสมพร้อมสลับโหมด
- **ลิงก์กระโดดตามกลุ่มคุณสมบัติ** — เมื่อส่วนโฟลเดอร์หรือส่วนฐานข้อมูลจัดกลุ่มตามคุณสมบัติแบบลิงก์สองทิศ คลิกชื่อกลุ่มเพื่อเปิดโน้ตเป้าหมาย
- **แก้ไขนับถอยหลังและหน้าเว็บ** — แก้ไขปฏิสัมพันธ์การเลือกเวลาเป้าหมายของนับถอยหลัง; การล็อกอิน Google OAuth จะเด้งไปยังเบราว์เซอร์ภายนอกเพื่อให้สิทธิ์ต่อ
- **ปรับปรุงการแสดงผลหลายภาษา** — เนื้อหาอินเทอร์เฟซอย่างปฏิทิน สภาพอากาศ ปฏิทินจันทร์คติ และความคืบหน้ารายปี แสดงตามภาษาปัจจุบัน

### 3.8.8
- **เสริมความแน่นให้ไปป์ไลน์การเก็บถาวร** — ตอนนี้การเก็บถาวรจะย้ายไฟล์ก่อน ตรวจสอบว่าการเปลี่ยนชื่อสำเร็จจริง (พร้อมลองใหม่อัตโนมัติหนึ่งครั้ง) แล้วจึงประทับสถานะ: ความล้มเหลวเงียบ ๆ ของการย้ายไฟล์บน vault ที่ซิงก์ผ่าน iCloud ไม่ทำให้โน้ตที่เก็บถาวรครึ่ง ๆ กลางคันค้างอยู่ในโฟลเดอร์สเตจอีกต่อไป (วินิจฉัยพบ 4 กรณี) หากการย้ายล้มเหลวจะแจ้งเตือนและปล่อยการ์ดไว้บนบอร์ด คลิกอีกครั้งก็ลองใหม่ได้เลย การย้ายด้วยการลากสเตจได้รับเกราะป้องกันแบบเดียวกัน
- **แก้ไขการลากจัดลำดับปุ่มสกิลบนการ์ด** — พบสาเหตุรากเหง้า: แม้จะยกเลิกการลากดั้งเดิมของการ์ดแล้ว Chromium ยังคงปล่อย pointer capture ของปุ่ม ทำให้ listener move/up ระดับปุ่มดับทันทีที่พอยน์เตอร์ออกนอกปุ่ม 22px — ซึ่งเป็นสิ่งจำเป็นสำหรับการจัดลำดับข้ามปุ่ม ท่าทางตอนนี้ทำงานบน capture listener ระดับเอกสาร: สลับตำแหน่งแบบเรียลไทม์ระหว่างลาก บันทึกลำดับเมื่อปล่อย และการวางบนปุ่มสกิลอื่นไม่สามารถเปิด modal ของปุ่มนั้นโดยไม่ตั้งใจอีกต่อไป
- **ปุ่มเปิดใช้งานแบบกำหนดเองบนการ์ดคลังสกิล** — เมนูการ์ดเพิ่ม "Configure launch buttons…": เลือกเอเจนต์ใดก็ได้ ป้ายชื่อ ไอคอน เทมเพลตพรอมต์ และสวิตช์ส่งตรงต่อหนึ่งสกิล ปุ่มกำหนดเองจะแสดงข้างปุ่มอัตโนมัติจากแหล่งที่มา — สกิลจากโฟลเดอร์ที่กำหนดเอง (ซึ่งไม่ผูกกับเอเจนต์) ในที่สุดก็มีจุดเข้าถึงการส่ง พร้อมบันทึกถาวรไปกับส่วนนั้น
- **เลย์เอาต์ modal ตั้งค่าไปป์ไลน์** — ตัวเลือกเอเจนต์เป็นช่องแคบคงที่ข้างช่องกรอกชื่อสกิล (ข้อความตัวเลือก "coming soon" ที่ยาวไม่ทำให้แถวบานอีกต่อไป) และเทมเพลตพรอมต์มีป๊อปอัปดูข้อความเต็ม — อ่านและแก้ไขทั้งหมดในหน้าต่างสูงหนึ่งบานโดยการแก้ไขไหลกลับแบบเรียลไทม์
- **ระยะเว้นด้านล่างของแดชบอร์ด** — เมื่อเลื่อนถึงสุด ส่วนสุดท้ายและปุ่มเพิ่มส่วนจะยกขึ้นให้พ้นหน้าต่างแชท AI ที่อยู่ด้านล่าง (60 → 200px บนเดสก์ท็อป) โทรศัพท์และเลย์เอาต์แบบ immersive คงค่าของตัวเองไว้

### 3.7.1
- **ส่วน RSS ใหม่ทั้งหมด** — ติดตามฟีด RSS 2.0 / Atom ใดก็ได้ และทุกแหล่งจะไหลรวมกันในสตรีมเรียงจากใหม่ไปเก่า: จุดยังไม่อ่านและตัวกรองยังไม่อ่าน กลุ่มแบ่งตามกลุ่มหรือตามฟีด (จัดการรายการกลุ่มได้ สร้างใหม่ได้ทันทีจากแถวฟีด) และแบ่งหน้าพร้อมกำหนดขนาดหน้าได้ (10/20/50/100) คลิกบทความเพื่ออ่านใน modal ผู้อ่านตามธีม — ฟีดที่ให้เฉพาะสรุปจะดึงหน้าเต็มและแยกเนื้อหาหลักอัตโนมัติ หากไม่สำเร็จจะเสื่อมไปใช้สรุปพร้อมปุ่มเปิดในเบราว์เซอร์ ทุกบทความบันทึกลง vault เป็นโน้ตได้ในคลิกเดียว (frontmatter จำลองตามเทมเพลตกล่องรับของ「01 收集」เพื่อป้อนไปป์ไลน์ PARA) และรายการที่บันทึกแล้วพาคุณไปยังโน้ตทันที มีนำเข้า OPML (หมวดหมู่กลายเป็นกลุ่ม ตัด URL ซ้ำ) และส่งออก ฟีดถูกแคชในเครื่อง 30 นาที (แหล่งที่ล้มเหลวลองใหม่ใน 5 นาที ความเข้มขนานอัธยาศัย 4 สาย) และฟีดที่มีปัญหาจะถูกระบุชื่อเป็นรายแถวพร้อมเหตุผลใน modal ตั้งค่า การเก็บสถานะอ่านเป็นตัวเลือกการตั้งค่า (30/90/180/365 วันหรือตลอดกาล)
- **แก้ไขการอ่านง่ายในเลย์เอาต์ immersive** — ข้อความในช่องกรอกมองไม่เห็นในเซสชัน Obsidian โหมดสว่าง (กฎ input ของ Obsidian มีลำดับความสำคัญสูงกว่าของปลั๊กอิน) และชื่อคอลัมน์คัมบังจางเป็นสีขาว (ขาด --db-bg ในบล็อกตัวแปร immersive) ทั้งสองแก้ที่รากเหง้า ปุ่มไอคอนเล็กในส่วนและ modal ไม่ถูกวาดทับหรือบีบให้แบนโดยปุ่มเนทีฟของ Obsidian อีกต่อไป
- **หมวดหมู่พรีเซ็ตของรายรับรายจ่ายแก้ไขได้แล้ว** — พรีเซ็ตทำงานเหมือนหมวดหมู่กำหนดเองทุกประการ: ลบ จัดลำดับ และจับคู่กลุ่มได้ทั้งหมด ประวัติยังแสดงภายใต้ป้ายที่ถูกลบ และชื่อที่ปลดออกสามารถเพิ่มกลับได้ แต่ละทิศทางคงหมวดหมู่ไว้อย่างน้อยหนึ่งหมวด
- **ตัดเมนูคลิกขวาของโหมด immersive ให้กระชับ** — ลบรายการ "จัดเรียงเลย์เอาต์" ที่ทำงานได้ไม่ดีออก เหลือ "ลบการ์ด" ไว้

### 3.7.0
- **เลย์เอาต์พื้นที่ทำงานแบบ immersive ใหม่ทั้งหมด** — ทุก workspace สลับเข้าโหมด immersive ได้: พื้นหลังโปสเตอร์เต็มจอพร้อมนาฬิกาและแถบจดบันทึกกึ่งกลาง และทุกวิดเจ็ต memo และ todo เป็นการ์ดแก้วที่ย้ายได้อิสระ — ปรับขนาดจากขอบ จัดตำแหน่งด้วยการสแนปอัจฉริยะ สร้างได้จากปุ่ม + บนตัวสลับ workspace

### 3.6.6
- **ธีมที่บันทึกไว้ใน Appearance Studio** — รูปลักษณ์ที่กำหนดเองบันทึกเป็นธีมพร้อมสลับใช้ได้ในคลิกเดียว พร้อมรายการคำสั่งด่วน
- **โล่ป้องกันการแฮ็กช่องกรอก** — snippet ของบุคคลที่สามไม่สามารถแฮ็กช่องกรอกของแดชบอร์ดด้วยสไตล์ global อีกต่อไป
- **แก้ไขการข้ามเพลงเงียบ ๆ ของ Music** — ความล้มเหลวในการเล่น NetEase บางครั้งไม่ข้ามเพลงเงียบ ๆ อีกต่อไป แต่แจ้งเตือนตามสาเหตุก่อน
- **ยกเพดานการเรนเดอร์** — การเรนเดอร์กลุ่มแบบก้าวหน้าจำกัดที่ 500 รายการ ส่วนขนาดใหญ่มากจึงแสดงตัวเองได้มากขึ้น

### 3.6.5
- **ลบการ์ดได้ในที่** — การ์ดแบบ grid, gallery และคัมบังในส่วน database/folder แสดงปุ่มถังขยะที่มุมเมื่อชี้เมาส์ (มองเห็นเสมอบนมือถือ) — ไม่ต้องไขว้เขวหาเมนูอีกต่อไป
- **สร้างโน้ตใหม่จากหลายเทมเพลต** — การตั้งค่า "เทมเพลตโน้ตใหม่" รองรับหลายเทมเพลตแล้ว เลือกหนึ่งเทมเพลตต่อการคลิก "+" บนแถบเครื่องมือ โดยโน้ตจะถูกกรอกตัวกรองของส่วนนั้นมาให้ล่วงหน้า การตั้งค่าเทมเพลตเดียวจะย้ายข้อมูลอัตโนมัติ
- **ควบคุมคอลัมน์มุมมองตาราง** — ปุ่มรูปตาบนแถบเครื่องมือแสดงรายการฟิลด์ property ทั้งหมด: ซ่อนสิ่งที่ไม่ต้องการและลากจัดลำดับ บันทึกค่าแยกตามส่วน การตั้งค่าคอลัมน์แบบเก่าย้ายข้อมูลอัตโนมัติ
- **ป้องกันการเรนเดอร์สำหรับ vault ขนาดใหญ่** — มุมมองแบบกลุ่มและคัมบังเรนเดอร์แบบก้าวหน้า (50 ต่อกลุ่ม/คอลัมน์พร้อมปุ่มแสดงเพิ่ม) และจำกัดที่ 2000 รายการพร้อมแจ้งเตือน — ส่วนที่มีไฟล์หลายพันไฟล์ไม่ทำให้แดชบอร์ดค้างอีกต่อไป
- **วันครบรอบจันทรคติ** — วันครบรอบเป็นวันจันทรคติได้ (เก็บเป็นวันสุริยคติแบบไม่สูญเสียข้อมูล) การแจ้งเตือนจะแมปกับวันครบรอบจันทรคติ
- **จุดโฟกัสปกและแบนเนอร์** — ปกโปรเจกต์และพื้นหลังแบนเนอร์ให้ลากเลือกตำแหน่งโฟกัส บันทึกค่าแยกตามภาพที่หมุนเวียน
- **เวลาและปลายทางของงานในปฏิทิน** — งานรองรับฟิลด์วันเริ่ม/ครบกำหนด/กำหนดการ พร้อมเวลาเสริมได้คร่อมหลายวัน (`[start::]`/`[due::]`/`[scheduled::]`) โหมดปลายทาง "หนึ่งโน้ตต่องาน" จะสร้าง/เพิ่มโน้ตตามวันที่ให้อัตโนมัติ
- **ส่วนแบบไม่มีปกรวมเข้า Notes** — ประเภท "โน้ตไม่มีปก" รวมเข้า "Notes" พร้อมสวิตช์ "แสดงปก" ต่อส่วน การตั้งค่าเก่าย้ายข้อมูลอัตโนมัติ
- **ตัวกรอง property สำหรับส่วน folder** — ส่วน Folder ได้ตัวแก้ไขตัวกรอง property เหมือนส่วน Database (equals/contains/notEquals)

### 3.6.3
- **การจัดกลุ่มสำหรับมุมมอง library/folder** — มุมมอง grid, gallery, list และ table ได้ปุ่ม "จัดกลุ่ม" บนแถบเครื่องมือ: ไม่จัดกลุ่ม, จัดตามโฟลเดอร์ (โฟลเดอร์ระดับบนสุดใต้โฟลเดอร์สแกน) หรือจัดตาม property ใน frontmatter ใดก็ได้ ตัวเลือกถูกบันทึกแยกตามส่วนในไฟล์บอร์ด มุมมองคัมบังคงใช้การจัดกลุ่มจาก dialog ตั้งค่าเดิม
- **ขยาย/ย่อทุกกลุ่ม** — เมื่อเปิดการจัดกลุ่ม ส่วน library/folder มีปุ่มบนแถบเครื่องมือที่ขยายหรือย่อทุกกลุ่มในคลิกเดียว ไอคอนและ tooltip เปลี่ยนตามสถานะปัจจุบัน
- **พื้นที่วิดเจ็ตปรับขนาดได้** — เลย์เอาต์แบบข้างกัน: ลากขอบแถบข้างเพื่อปรับความกว้าง (180–420px บันทึกค่าไว้) เลย์เอาต์แบบซ้อน: ลากแถบวิดเจ็ตเพื่อกำหนดความสูง (240–560px) ระดับความสูงของวิดเจ็ตนิสัยและการอ่าน (เต็ม / สองในสาม / ครึ่ง / หนึ่งในสาม) เลือกได้ในการตั้งค่า
- **แก้ไขการเล่นเพลงของวิดเจ็ต Music** — ความผิดพลาดสิทธิ์ NetEase -110 ที่เกิดเป็นครั้งคราวจะลองใหม่แบบเว้นช่วงก่อนยอมแพ้ เพลงที่มีสิทธิ์จึงไม่ถูกข้ามอีกต่อไป เพลงที่เล่นจริงไม่ได้จะระบุชื่อและเหตุผล (สมาชิก การซื้อ หรือสิทธิ์ตามภูมิภาค) ในการแจ้งเตือนก่อนไปเพลงถัดไป — ไม่มีการกระโดดเงียบ ๆ อีกต่อไป
- **เก็บถาวรไปยัง daily note ของวันนี้ในคลิกเดียว** — การตั้งค่าใหม่ "ปลายทางการเก็บถาวร": ไฟล์คงที่ (เหมือนเดิม) หรือ daily note ของวันนี้ (สร้างอัตโนมัติจากเทมเพลต/พาธของปลั๊กอิน Daily notes หากยังไม่มี) หากระบุ daily note ไม่ได้ การเก็บถาวรจะยกเลิกพร้อมแจ้งเตือน
- **เทมเพลตกำหนดเองสำหรับบันทึก memo** — การบันทึกการ์ด memo/sticky เป็นโน้ตรองรับเทมเพลตกำหนดเองแล้ว
- **แก้ไขประสิทธิภาพการรีเฟรช** — การเปลี่ยนแปลงใน vault จะสร้างใหม่เฉพาะส่วนที่ขอบเขตสแกนครอบคลุมพาธที่เปลี่ยน: การแก้ไขโน้ตที่อื่น RSS ดรอป และการเปลี่ยนรูปภาพไม่ทำให้ทุกส่วน library/folder กระพริบอีกต่อไป ส่วนที่ผลคำสั่งค้นหาไม่เปลี่ยนจะข้ามการสร้างใหม่ทั้งหมด (การแก้ไขนอกขอบเขต: จาก 3 ส่วนต่อรอบ → 0)
- **คงตำแหน่งเลื่อนไว้ทุกที่** — การเรนเดอร์ใหม่ทั้งหมดจะสแนปช็อตสถานะการเลื่อนของทั้งหน้า (การเลื่อนแนวนอนของชั้นวิดเจ็ตแบบซ้อน, พื้นที่เลื่อน, ชั้นการ์ด, รายการงาน, รายการภายในวิดเจ็ต) แล้วเล่นซ้ำอย่างแม่นยำ คีย์แบบ anchor รอดจากการจัดลำดับส่วน/วิดเจ็ตใหม่ — ที่ที่คุณกำลังทำงานคือที่ที่คุณยังอยู่ ไม่ต้องกระโดดกลับขึ้นบนสุดอีกต่อไป

### 3.6.2
- **โทนสีและพรีเซ็ตใน Theme Studio** — ทุกพื้นที่สีมี dropdown เลือกโทน (ตามธีม / สว่าง / มืด / กำหนดเอง, สูตรสีพื้นหน้าของพื้นหลังวิดเจ็ต) พร้อมพรีเซ็ตต่อฟิลด์สำหรับเลือกอย่างรวดเร็ว
- **สร้างโน้ตใหม่ในส่วน Notes** — ส่วนโน้ตมีปกและไม่มีปกได้ปุ่ม "โน้ตใหม่" ต่อการ์ด พร้อมการตั้งค่าส่วนสำหรับเทมเพลตโน้ตใหม่และโฟลเดอร์บันทึก (ราก vault หากไม่ระบุ)
- **การ์ด Memo เรนเดอร์ markdown** — การ์ด memo และ sticky เรนเดอร์เนื้อหาผ่านตัวเรนเดอร์ของ Obsidian (ปรับให้คงบรรทัดเดิม memo เดิมคงหน้าตาเดิม)
- **แก้ไข** — เทมเพลตโน้ตใหม่ของส่วน folder ถูกทิ้งเงียบ ๆ ตอนบันทึกการตั้งค่า ตอนนี้ frontmatter ของเทมเพลตถูกรวมใต้ property ตัวกรองโดยคงบรรทัดดิบไว้

### 3.6.1
- **แถบเครื่องมือของส่วนยุบเป็นปุ่ม dropdown** — ตัวสลับมุมมองและตัวควบคุมขนาดการ์ด (S/M/L) ในส่วน library/folder/images/videos แต่ละตัวยุบเป็นปุ่มเดียวที่แสดงตัวเลือกปัจจุบัน คลิกเพื่อเปิดเมนูเนทีฟเพื่อเลือก — แถบเครื่องมือเงียบลงมาก
- **ขอบเขตการแสดงผลของ Images/videos** — การตั้งค่าใหม่ "ขอบเขตการแสดงผล": เลือกหลายโฟลเดอร์ใน vault (มีตัวช่วยเลือก) เมื่อตั้งค่า จะแสดงเฉพาะไฟล์ใต้โฟลเดอร์เหล่านั้น (การยกเว้นยังใช้ได้ภายในขอบเขต) ว่าง = ทั้ง vault
- **เทมเพลตโน้ตใหม่ต่อส่วน** — dialog ตั้งค่า folder/library มี "เทมเพลตโน้ตใหม่": โน้ตที่สร้างจากปุ่ม "+" บนแถบเครื่องมือเริ่มจากเนื้อหาเทมเพลต (แทนที่ {{title}} และ {{date:…}}) พร้อม property ตัวกรองของส่วนกรอกล่วงหน้าตามเดิม หากไม่มีเทมเพลตจะเสื่อมไปเป็นโน้ตเปล่า
- **ปลายทางงานของปฏิทิน** — การตั้งค่าปฏิทินมี "ปลายทางงาน": คงโซ่ค่าเริ่มต้น (daily note ของวันนั้น → รายการ todo ของแดชบอร์ด) หรือระบุไฟล์ใดไฟล์หนึ่ง (แทรกบน/ล่าง) หรือโฟลเดอร์ (โน้ต YYYY-MM-DD หนึ่งไฟล์ต่อวัน สร้างอัตโนมัติ)
- **ปุ่ม quick action เป็นแก้วในทุกธีม** — สีพื้นและขอบปุ่มของ Earth/Nordic/Island/Tundra/Matcha/Lilac/Vermilion/Aurora เป็นแก้วโปร่งแสงอมโทนเน้นสีแล้ว เทียบเท่ากับห้าธีมที่มีมาก่อน — ทั้งสิบสองรู้สึกเหมือนกัน
- **แก้ไข alpha และพื้นหลังหน้าใน Theme Studio** — ทุกแถวสีมีตัวเลื่อนความทึบ (0–100%) พื้นหลังหน้าแบบกำหนดเองใช้งานได้จริงแล้ว (gradient ของธีมละอองสีถูกแทนที่ด้วย) และ alpha 0 จะเผยพื้นหลังของ Obsidian
- **แผงด้านในแบบฝ้าบนการ์ดพื้นหลังรูปภาพ** — เมื่อตั้งรูปพื้นหลัง แผงแก้วฝ้าแยกจะลอยอยู่เหนือภาพ (เบลอจริง + สีพื้นการ์ดตามธีม + ขอบบนสว่าง) วิดเจ็ต pomodoro เข้าร่วมชมรมพื้นหลังรูปภาพด้วย (ไอคอนเฟืองในกลุ่มแถวบน)
- **การปรับแต่งจำนวนมาก** — ที่คั่นหน้าบนแบนเนอร์ที่ยุบจะหดหายจนกว่าจะชี้เมาส์ ปุ่ม palette quick-actions ถูกลบ (รูปภาพ + สีพื้นหน้าแทนที่แล้ว) ปุ่มหัวข้อของวิดเจ็ตนิสัยมองเห็นเสมอ สีพื้นหน้ากำหนดเองพลิกข้อความที่สืบทอดด้วย (แก้ป้ายชื่อ quick-action ให้ตรง) แก้วิดเจ็ตจันทรคติเสียการลากจัดลำดับหลังรีเฟรชแบบ async (event delegation) แก้การลากคู่ความกว้างเสียบน Windows (ค่า partner เก่าวนกลับ + การปัดเศษ subpixel + เหตุการณ์ถูก webview กลืน ครบทั้งสามราก)

### 1.1.4
- **งานย่อยยุบได้** — งานที่มีงานย่อยยุบได้แล้ว สถานะยุบอยู่รอดข้ามการโหลดใหม่ เฉพาะรายการที่มีลูกแสดงลูกศรสลับ รายการใบจึงไม่มี padding ซ้ายเพิ่มและรายการยังกระชับ
- **ลิงก์เอกสารซ้อน (sub-documents) ในการ์ดโปรเจกต์** — ลิงก์เอกสารในการ์ดโปรเจกต์รองรับการซ้อนเหมือนงานย่อย: ลากไฟล์หนึ่งไปวางบนอีกไฟล์เพื่อซ้อน (โซนวางก่อนหน้า / ถัดไป / ซ้อน) และยุบ sub-documents ของ parent ได้ บันทึกเป็นรายการ Markdown ซ้อนแบบเยื้องลิงก์จึงยังถูกต้องในทุกมุมมอง Obsidian (ไม่มีความเสียหาย code-block จากการเยื้อง)
- **งานซ้อน (งานย่อย)** — งานรองรับการซ้อนหลายระดับ บันทึกเป็น Markdown เยื้องลากงานไปวางบนอีกงานเพื่อซ้อน (โซนก่อนหน้า / ถัดไป / ซ้อน) จัดลำดับงาน หรือย้ายข้ามการ์ด บนมือถือกดค้างเพื่อลากและปัดแนวนอนเพื่อซ้อน/ถอนซ้อน การติ๊กงาน parent จะติ๊กลูกทั้งหมด
- **ธีมใหม่สองแบบ: Mono และ Onyx** — เพิ่ม Mono (ดำ/ขาวล้วนมินิมอล ต่อมาเปลี่ยนชื่อเป็น Vermilion — มินิมอลลายหมึกพร้อมเน้นตราชาด) และ Onyx (ดำล้วนพร้อมเน้นเลมอน เหมือนกันทั้งสว่างและมืด) ลบธีม Spring (Prism)
- **เพิ่มความสามารถวิดเจ็ต Heatmap** — ฮีตแมปในแถบข้างแก้ไฟล์ journal รายวันจากโฟลเดอร์ที่กำหนดได้ รองรับชื่อแสดงผลกำหนดเอง และมีสองโหมดช่วง: หน้าต่างเลื่อน (N วันล่าสุด) หรือช่วง (เดือน/ไตรมาส/ปีปัจจุบัน)
- **ปฏิทินแถบข้างรีเฟรชอัตโนมัติ** — ปฏิทินรายสัปดาห์ในแถบข้างอัปเดตไฮไลต์ "วันนี้" และวันที่อัตโนมัติหลังเที่ยงคืน แม้มุมมองแดชบอร์ดถูกปักหมุดเปิดไว้ (ก่อนหน้าค้างอยู่ที่วันที่เปิดครั้งแรก)
- **ตั้งชื่อ quick action เองได้** — เมื่อเพิ่ม quick action แบบไฟล์หรือคำสั่ง คุณตั้งชื่อแสดงผลกำหนดเองได้ (และเลือกไอคอน) ในขั้นยืนยัน แทนการติดชื่อเริ่มต้น
- **แก้เงาค้างการลากบนมือถือ** — การกดค้างการ์ดเพื่อลากบนมือถือไม่ทิ้งเงาข้อความถาวรบนจออีกต่อไปเมื่อการสัมผัสถูกระบบขัดจังหวะ (ท่าทางขอบ การแจ้งเตือน การแฮ็กการเลื่อน) handler touchcancel ล้าง ghost ของการลาก ghost ที่ค้างถูกกวาดเมื่อเรนเดอร์ใหม่ และทรานซิชันบน ghost clone และการ์ดที่ลากถูกปิดเพื่อขจัดเงาทอด
- **บันทึก memo เป็นโน้ต** — การ์ด memo บันทึกเป็นโน้ตแยกใน vault ได้ผ่านปุ่ม "Save as note" ใหม่ พร้อมโฟลเดอร์บันทึกที่กำหนดได้ (การตั้งค่า memoSavePath)

### การล็อกอินบัญชี NetEase และความเป็นส่วนตัว

บนเดสก์ท็อป เปิด Settings → Apex Dashboard → Widgets → Music แล้วเลือก Phone / NetEase sign in ทำการล็อกอินด้วยโทรศัพท์บนเว็บไซต์ทางการหากมีให้ NetEase อาจต้องการการล็อกอินด้วย QR ไม่มี endpoint SMS แยกในปลั๊กอินนี้ สถานะสมาชิก การซื้อ และสิทธิ์ตามภูมิภาคถูกตรวจโดย NetEase คลิปทดลองไม่ถูกเล่นเป็นเพลงเต็ม

ข้อมูลรับรองถูกส่งตรงไปยัง NetEase ปลั๊กอินใช้เซสชันในเครื่องสำหรับคำขอบัญชีและ URL การเล่น Cookies อยู่ในเซสชัน Electron ของ Obsidian แบบแยกในเครื่อง อยู่นอก data.json และ vault sync การออกจากระบบจะหยุดการเล่นและล้างเซสชันในเครื่องนั้น ล็อกอินใหม่หากหมดอายุ ไม่มีการใช้พร็อกซีบุคคลที่สาม

### ย้ายการ์ดข้ามส่วน

ลากหัวข้อการ์ดระหว่างส่วน Todo, Memo และ Sticky โน้ตที่มีหรือไม่มีปกยังย้ายเข้าส่วนเหล่านี้ได้ด้วย ปลายทาง Memo แสดงข้อความต้นฉบับ งาน และลิงก์เป็น memo ปลายทาง Todo คงงานที่มีอยู่และเปลี่ยนบรรทัดข้อความที่ไม่ว่างอื่นและลิงก์โน้ตเป็นรายการที่ยังไม่ติ๊ก ปลายทาง Sticky คงหน้าตาการ์ดต้นฉบับ รวมถึงว่าโน้ตมีปกหรือไม่ การเปลี่ยนแปลงคงอยู่ข้ามการโหลดใหม่ การย้ายการ์ดบนบอร์ดไม่ย้ายหรือลบไฟล์ใน vault ที่เชื่อมโยงกัน

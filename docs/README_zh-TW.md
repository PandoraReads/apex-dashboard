## 功能特色

### 🗒️ Memo（備忘）
內建便籤式 Memo 卡片，每張卡片都有可編輯的文字區域，隨時記錄靈感、會議筆記或每日反思，無需離開儀表板。支援 `[[双链]]` 渲染為可點擊的連結，輕鬆關聯筆記。

### ✅ Todo（待辦事項）
互動式任務清單，支援新增、拖曳排序、勾選完成。底部的進度條會以百分比即時顯示完成進度。待辦事項同樣支援 `[[双链]]`，方便交叉參照。

### 📁 Projects（專案）
將儲存庫中的文件組織為專案卡片。每張卡片可關聯多篇筆記，支援封面圖片（支援本機儲存庫圖片與網路圖片連結）和內嵌文件搜尋，快速加入檔案。支援管理多種檔案類型，包括 Markdown 筆記、PDF、圖片、音訊和影片。

### 📝 Notes（筆記）
緊湊的列表式分區，用於整理參考文件與快速存取檔案。每列最多顯示 5 張卡片，無封面圖片，將資訊密度最大化。

### 📅 日曆（Calendar）
原生月曆格狀顯示，彙整整個儲存庫所有帶有日期的任務（無需 Dataview 或外部外掛）。每一格列出當天任務，點擊格子可查看當日行程；可開啟全螢幕大月曆，支援月份切換與就地勾選。多日行程（`[start::]`/`[end::]`）會跨天顯示。側邊欄日曆小工具的全螢幕放大檢視也可以作為**日曆分區**直接嵌入工作台：完整月曆檢視（多日橫條）與週時間軸網格、任務篩選、跳至今日一應俱全，點擊日期數字即可為該日新增待辦事項（自動寫入日記或工作台待辦事項清單）。

### 🔍 查詢（Dataview）
使用內建 DQL 引擎查詢整個儲存庫，無需安裝 Dataview 外掛。新增查詢分區後即可撰寫查詢語句，例如 `TABLE file.name, rating FROM "Books" WHERE rating >= 4 SORT rating DESC`。支援 `TABLE`、`LIST`、`TASK`、`CALENDAR`、`HEATMAP` 五種輸出，來源可用資料夾、標籤、連結（`FROM`），搭配 `WHERE`、`SORT`、`GROUP BY`、`FLATTEN`、`LIMIT` 子句、約 40 個內建函式、全部 `file.*` 隱式欄位、YAML frontmatter 與行內欄位（`[key:: value]`）。設定彈出視窗會即時驗證語法並提供一鍵範例查詢。`TASK` 核取方塊可直接回寫來源筆記，`CALENDAR` 會繪製月曆網格，`HEATMAP` 則可用任意數值欄位繪製年度貢獻熱力圖。結果可透過分區的重新整理按鈕按需更新。

### 🌐 網頁（Web）
在分區內嵌入任意網頁：填入網址即可像內嵌瀏覽器面板一樣瀏覽。嵌入引擎全自動——預先檢查網站的嵌入政策，允許 iframe 的網站直接嵌入；拒絕嵌入的網站在桌面版會自動改用獨立的網頁檢視（webview，內建持久登入狀態，Google Keep、滴答清單網頁版等需要登入的應用程式皆可使用），行動裝置上則顯示備援卡片並提供「在瀏覽器中開啟」。顯示比例提供 50%–125% 的預設按鈕（資訊密集的 Web 應用程式可縮小顯示）。行動裝置建議嵌入 https 網站；嵌入以瀏覽為主，彈出視窗與下載請在系統瀏覽器中進行。

### 📡 RSS 訂閱
把部落格與資訊來源訂閱進工作台：新增任意 RSS 2.0 / Atom 連結後，各來源最新文章會按時間倒序混合成一條資訊流（帶有來源名稱標籤、未讀圓點），支援未讀篩選與一鍵全部標記已讀。點擊條目即可在彈出視窗中直接閱讀全文——優先使用訂閱本身提供的全文，只有摘要的來源會自動擷取原始網頁並擷取正文；每條上的下載按鈕可將文章一鍵儲存為儲存庫筆記（以日期命名 + 來源 frontmatter + 原文連結，統一存入設定的資料夾），已儲存的條目再次點擊即會跳轉至筆記。feed 內容在本機快取 30 分鐘，已讀與下載狀態會跨工作階段保留。

### ⚡ 快捷操作
將常用的捷徑釘選到側邊欄，支援兩種操作類型：**檔案**連結可開啟任意文件，**命令**捷徑可觸發任意 Obsidian 命令。內建「新增日記」與「新增筆記」預設項目。

### 常用操作列中的技能按鈕

在常用操作列的設定中新增「技能按鈕」，填寫按鈕名稱和技能名稱。點擊按鈕後可輸入補充內容並預覽提示詞，再傳送到 Claudian 或 Copilot 目前的對話。選擇 Codex Desktop 時，工作台會透過官方 `codex://` 深層連結建立新的 Codex 對話並預填提示詞；使用者需要在 Codex 中按 Enter 執行。模板可使用 `{skill}` 和 `{input}`；Claudian、Codex 預設使用 `$技能名稱`，Copilot 預設使用 `/技能名稱`。技能由使用者自行安裝與維護。

Claudian 與 Copilot 需要在桌面版 Obsidian 中啟用對應的外掛。Codex 目標需要安裝 Codex 桌面版並註冊 `codex://` 連結處理程式。工作台不會呼叫 Codex CLI，也不會代替使用者提交 Codex 中預填的提示詞。

### 🌤️ 側邊欄小工具
左側欄提供 11 種可獨立開關、可拖曳排序的小工具：

- **天氣** — 即時天氣（溫度、體感溫度、溼度、風速）+ 5 日預報（每日圖示與最高／最低溫）。基於 Open-Meteo，無需 API key；城市搜尋自動補全以精確定位
- **農曆黃曆** — 農曆日期、傳統節日與宜忌速覽
- **番茄鐘** — 專注計時器：活動標籤、專注／休息循環、今日活動分佈甜甜圈圖；統計頁面提供目標進度、效率分數、趨勢圖、12 週熱力圖與今日時間軸
- **閱讀追蹤** — 豆瓣搜書或手動新增書目，計時閱讀並按頁碼記錄進度；書卡顯示封面、作者與進度條
- **倒數計時** — 自訂多個目標日期，按天／小時顯示剩餘時間
- **年度進度** — 今年已流逝百分比一覽
- **日曆** — 月／週雙檢視日曆網格，彙整全庫帶有日期的任務；點擊日期查看行程、可直接新增任務（自動寫入當日日記），多日事件橫跨顯示
- **習慣打卡** — 每日勾選打卡，支援補昨天打卡、連續天數與熱力圖統計
- **記帳** — 快速記錄收支（備註、補記、自訂類別），今日小計與週／月／年／全部統計，明細帳本支援篩選、編輯與 CSV 匯入匯出
- **相簿** — 像電子相框一樣自動輪播指定資料夾的圖片：滑鼠懸停暫停、左右手動切換與序號角標，1:1 / 3:4 面板比例，淡出、左推、右推、放大淡入四種切換動畫，可選擇是否遞迴子資料夾；輪播間隔 3–60 秒可調，資料夾內圖片新增、刪除或改名後會原地重新整理、不打斷目前的播放位置
- **音樂** — 側欄搜尋並播放網易雲音樂的免費歌曲（可在設定中登入網易雲帳號，依帳號權限播放會員歌曲），支援貼上歌單連結一鍵匯入、音量與循環模式、播放清單持久化（封面延遲載入補全），播放時可選擇顯示全域浮動迷你播放列（關閉儀表板也能控制；僅桌面版）

側欄還常駐 **週曆條**（7 天緊湊列、醒目提示今天）、**最近文件** 與 **捲動回頂** 按鈕；行動裝置有同款小工具列，小工具資料會跨裝置同步合併。

### 🎨 Banner（橫幅）
可自訂的橫幅區域，支援編輯引言和背景圖片（支援本機儲存庫圖片與網路圖片連結）。雙擊即可修改。

### 🔄 拖曳排列
在分區之間拖曳卡片來重新組織工作空間，也可以在 Todo 卡片內拖曳任務項目進行排序，還支援在 Projects/Notes 卡片之間拖曳文件連結。

### 🧩 自訂分區
共 **15 種分區類型**自由組合 — **待辦事項**、**備忘**、**便利貼**、**筆記（專案卡）**、**無封面筆記**、**資料檢視**、**資料庫**、**資料夾**、**圖片**、**影片**、**日曆**、**微信讀書**、**滴答清單**、**網頁**、**RSS 訂閱** — 每種類型都有獨立的版面與互動，打造專屬工作流程。

### 🕐 最近文件
側邊欄顯示最近編輯的檔案及相對時間，快速回到最近的工作。

## 設定選項

- **Dashboard 檔案路徑** — 自訂儀表板資料檔案的存放路徑
- **樣式** — 從 13 款視覺主題中選擇
- **語言** — 支援簡體中文、繁體中文、英語、日語、韓語、西班牙語、法語、德語、巴西葡萄牙語、俄語和泰語。新安裝預設跟隨 Obsidian 的介面語言，也可在外掛設定中單獨選擇；命令面板中的語言命令會開啟語言選擇清單。介面譯文隨外掛離線打包。
- **最近文件數量** — 控制側邊欄顯示的最近檔案數量

## 安裝

### 從 Obsidian 社群外掛市場安裝
1. 開啟 設定 > 第三方外掛
2. 瀏覽並搜尋 "Apex Dashboard"
3. 點擊安裝，然後啟用

### 手動安裝
1. 從 [GitHub Releases](https://github.com/pandorareads/apex-dashboard/releases) 下載最新版本
2. 解壓縮到儲存庫的 `.obsidian/plugins/apex-dashboard/` 目錄
3. 開啟 設定 > 第三方外掛，啟用 "Apex Dashboard"

## 使用方法

1. 透過左側功能區圖示（首頁圖示）或命令面板開啟：`Apex Dashboard: Open dashboard`
2. 第一次使用會在儲存庫根目錄自動建立 `dashboard.md` 檔案
3. 所有變更直接儲存到檔案 — 純文字格式，你的資料完全屬於你

> **注意：** 刪除、重新命名或對分區進行排序，需要在 `dashboard.md` 筆記中進行操作。在筆記中的任何修改，會在工作台介面中直接生效。

### 跨分區移動卡片

拖動卡片標題列，可在待辦事項清單、備忘錄和便利貼之間移動卡片。有封面及無封面的筆記卡片也可移入這三個分區。

- 移入備忘錄：變為備忘卡片，顯示原文字、任務、勾選狀態及筆記連結。
- 移入待辦事項清單：變為待辦事項卡片，原有任務保留；其他文字按非空行轉成未完成條目，筆記連結也作為條目保留。
- 移入便利貼：保留原形態；筆記卡片保留有封面／無封面的區別。

跨區後會重新繪製卡片並更新操作入口，儲存、重新開啟仍保持轉換結果。移動的是工作台卡片，不移動或刪除其連結的筆記檔案。

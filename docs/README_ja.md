# Apex Dashboard

> Obsidian のノートを行き来するのはもう終わり。たった 1 ページに、必要なものがすべて。考えをメモし、ToDo を片付け、プロジェクトを追跡 — しかも驚くほど美しい見た目で。

## 機能

### 🗒️ メモ
内蔵のメモパッドで、思いついたことをすぐに書き留められます。各メモカードには書き込み可能なテキストエリアがあり、ダッシュボードを離れることなくアイデア、議事録、日々の振り返りなどを記録できます。`[[wikilinks]]` に対応しており、クリック可能なリンクとして表示されます。

### ✅ Todo
インタラクティブなチェックリストでタスクを管理します。タスクの追加、並べ替え、ドラッグ＆ドロップ、完了チェックが可能です。進捗バーで達成率がひと目でわかります。Todo 項目も `[[wikilinks]]` に対応しており、ノート間の相互参照ができます。

### 📁 プロジェクト
Vault 内のドキュメントをプロジェクトカードとして整理します。各カードは関連ノートへリンクし、カバー画像を表示できます（Vault 内のローカル画像と Web URL の両方に対応）。インラインのドキュメント検索にも対応しており、新しいファイルを素早く追加できます。Markdown ノート、PDF、画像、音声、動画など複数のファイル形式を管理できます。

### 📝 ノート
リファレンスドキュメントや素早くアクセスしたいファイルを整理するための、コンパクトなリスト形式のセクションです。カバー画像なしで 1 行あたり最大 5 枚のカードを表示し、高い情報密度を実現します。

### 📅 カレンダー
Vault 内のすべての日付付きタスクを表示するネイティブの月間カレンダー（Dataview や外部プラグインは不要）。各日付セルにはその日のタスクが一覧表示され、日付をクリックするとその日のアジェンダが開きます。月移動とインラインでのタスク切り替えができる全画面カレンダーも開けます。`[start::]` / `[end::]` を持つ複数日イベントは日をまたいで表示されます。サイドバーウィジェットの拡大表示は、ボードに埋め込まれる**カレンダーセクション**としても利用できます — 完全な月間グリッド（複数日バー付き）、週タイムグリッド、タスクフィルター、今日へのジャンプに対応し、日付の数字をクリックするとその日のタスクを追加できます（デイリーノートまたはダッシュボードの Todo リストに書き込まれます）。

### 🔍 Dataview
内蔵の DQL エンジンで Vault にクエリを実行 — Dataview プラグインは不要です。Dataview セクションを追加して、`TABLE file.name, rating FROM "Books" WHERE rating >= 4 SORT rating DESC` のようなクエリを書けます。フォルダ・タグ・リンク（`FROM`）を対象に、`TABLE`、`LIST`、`TASK`、`CALENDAR`、`HEATMAP` 出力に対応し、`WHERE`、`SORT`、`GROUP BY`、`FLATTEN`、`LIMIT` 句、約 40 個の組み込み関数、すべての `file.*` 暗黙フィールド、YAML frontmatter、インラインフィールド（`[key:: value]`）をサポートします。設定モーダルは構文をリアルタイムで検証し、ワンクリックのサンプルクエリを同梱しています。`TASK` のチェックボックスは元のノートに書き戻され、`CALENDAR` は月間グリッドを、`HEATMAP` は任意の数値フィールドから年間コントリビューショングリッドを描画します。結果はセクションの更新ボタンからいつでも再取得できます。

### 🌐 Web
任意の Web ページをセクションに直接埋め込めます — URL を貼り付ければ、ボード内ブラウザのように閲覧できます。**自動モード**はサイトのフレーム埋め込みポリシーを事前チェックします。フレーム埋め込み可能なサイトは iframe としてそのまま埋め込まれ、拒否するサイトはデスクトップでは webview に切り替わります（独自の永続ログインを持つため、Keep、Todoist Web などのサインイン系アプリに推奨）。モバイルでは「ブラウザで開く」ボタン付きのフォールバックカードが表示されます。iframe/webview モードの強制指定も可能で、高密度な Web アプリ向けにページを 0.5〜2 倍に拡大縮小できます。モバイルでは https サイトを推奨。埋め込みは閲覧目的のものです — ポップアップやダウンロードは実際のブラウザで行ってください。

### 📡 RSS
ブログやニュースフィードをボード上で直接購読できます。RSS 2.0 / Atom のリンクを追加すると、すべてのフィードの最新記事が新しい順の 1 つのリストにまとまって流れてきます（ソースタグ、未読ドット付き）。未読フィルターと「すべて既読」にも対応しています。エントリをクリックするとモーダルで全文を読めます — 全文を配信しているフィードはそのまま表示され、要約のみのフィードは自動的にページを取得して本文を抽出します。すべてのエントリにダウンロードボタンがあり、記事を Vault のノートとして保存できます（日付プレフィックス付きの名前、ソース frontmatter、元リンクを付けて設定フォルダに保存）。保存済みのエントリからはそのノートへ直接ジャンプできます。フィードの内容は 30 分間ローカルにキャッシュされ、既読・保存状態はセッションをまたいで保持されます。

### ⚡ クイックアクション
よく使うショートカットをサイドバーにピン留めできます。アクションには 2 種類あります。任意のドキュメントを開く**ファイル**リンクと、任意の Obsidian コマンドを実行する**コマンド**ショートカットです。新しいジャーナル作成と新しいノート作成の組み込みプリセットも含まれています。

### 🌤️ サイドバーウィジェット
左サイドバーには、個別にオン/オフでき、ドラッグで並べ替えられる 11 種類のウィジェットがあります。

- **天気** — 現在の気温、体感温度、湿度、風速、そして毎日の最高/最低気温付きの 5 日間予報を含むリアルタイム天気。Open-Meteo による（API キー不要）。位置情報のオートコンプリート付き都市検索で正確な場所を設定できます
- **旧暦暦（Lunar Almanac）** — 伝統的な中国の旧暦の日付、祝祭日、その日の行動指針（向き不向き）
- **ポモドーロタイマー** — アクティビティ選択と作業/休憩サイクルを備えた集中タイマー。今日の内訳を示すドーナツチャート付き。統計ビューでは、目標進捗、効率スコア、トレンドチャート、12 週間のヒートマップ、今日のタイムラインも確認できます
- **読書トラッカー** — 内蔵タイマーで読書セッションを記録します。Douban 検索または手動入力で本を追加し、読書時間を計測してページ数で進捗を記録できます。各本のカードにはカバー画像、著者、読書進捗バーが表示されます
- **カウントダウン** — 任意の目標日までのカウントダウンをカスタマイズでき、残り日数または残り時間で表示できます
- **年間進捗** — 今年がどれだけ経過したかを表示します
- **カレンダー** — Vault 全体の日付付きタスクを集約する月/週グリッド。日付をクリックするとその日のアジェンダを開き、タスクを追加するとその日のデイリーノートに書き込まれます。複数日イベントは日をまたいで表示されます
- **習慣チェックイン** — 習慣ごとの毎日のチェックに対応し、前日の遡及入力、連続記録（ストリーク）、ヒートマップ統計を備えています
- **支出トラッカー** — 支出/収入のクイック入力（メモ、日付遡及、カスタムカテゴリ対応）と今日の合計、週/月/年/全期間の統計。台帳ではフィルタリング、インライン編集、CSV のインポート/エクスポートが可能です
- **フォトアルバム** — 任意の Vault フォルダのためのデジタルフォトフレーム：ホバーで一時停止する自動ローテーション、手動の前/次ボタンとインデックスバッジ、1:1 または 3:4 のパネル比率、4 種類のトランジション（フェード / 左プッシュ / 右プッシュ / ズーム）、3〜60 秒の間隔、サブフォルダをデフォルトで含みます。最初に表示される写真は時刻シードで決まるため（いつも同じにはならない）、次の写真はプリロードされ、Vault での追加/削除/リネーム時にも表示位置を失わずにリストがその場で更新されます
- **音楽** — サイドバーから NetEase Cloud Music の無料楽曲を検索して再生できます：設定で NetEase アカウントにログインするとアカウント権限の会員楽曲も再生可能、プレイリストのリンクを貼り付けてインポート、音量とリピートのコントロール、遅延カバーバックフィル付きの永続化プレイリスト、ダッシュボードを閉じても動作し続けるオプションのフローティングミニプレイヤーバー（デスクトップのみ）

サイドバーには、**週間カレンダーストリップ**（コンパクトな 7 日間、今日をハイライト）、**最近のドキュメント**、**トップへスクロール**ボタンもあります。スマートフォンでも同じウィジェットバーが使え、ウィジェットデータはデバイス間で union マージされます。

### 🎨 バナー
インスピレーションを与える引用とオプションの背景画像を備えた、カスタマイズ可能なバナーです。Vault 内のローカル画像と Web URL の両方に対応。ダブルクリックで編集できます。

### 🔄 ドラッグ＆ドロップ
セクション間でカードをドラッグして、ワークスペースを再編成できます。Todo カード内でタスク項目をドラッグして並べ替えられます。プロジェクト/ノートカード間でドキュメントリンクをドラッグできます。

### 🧩 カスタムセクション
**15 種類のセクションタイプ**を自由に組み合わせられます — **Todo**、**メモ**、**付箋**、**ノート（プロジェクトカード）**、**ノート（カバーなし）**、**Dataview**、**ライブラリ**、**フォルダ**、**画像**、**動画**、**カレンダー**、**Weread**、**TickTick**、**Web**、**RSS** — それぞれが独自のレイアウトと動作を持ち、ボードをあなたのワークフローに合わせられます。

### 🕐 最近のドキュメント
サイドバーには最近編集したファイルが相対的なタイムスタンプ付きで表示されるため、最新の作業にすぐに戻れます。

## 設定

- **ダッシュボードファイル** — ダッシュボードデータのファイルパスをカスタマイズ
- **スタイル** — 13 のビジュアルテーマから選択
- **言語** — 英語または中国語のインターフェース
- **最近のドキュメント数** — 表示する最近のファイル数を制御
- **サイドバーウィジェット** — 天気、ヒートマップ、ポモドーロ、読書、カウントダウン。各ウィジェットを個別に有効/無効化・設定できます
- **読書設定** — 読書トラッカーの切り替え、セッション完了時のサウンドの有効/無効

## インストール

### Obsidian コミュニティプラグインから
1. 設定 > コミュニティプラグインを開く
2. 「Apex Dashboard」を検索
3. 「インストール」をクリックし、「有効化」をクリック

### 手動インストール
1. [GitHub Releases](https://github.com/pandorareads/apex-dashboard/releases) から最新のリリースをダウンロード
2. Vault の `.obsidian/plugins/apex-dashboard/` フォルダに展開
3. 設定 > コミュニティプラグインで「Apex Dashboard」を有効化

## 使い方

1. リボンアイコン（ホームアイコン）またはコマンドパレットから `Apex Dashboard: Open dashboard` でダッシュボードを開きます
2. `dashboard.md` ファイルが Vault のルートに自動的に作成されます
3. すべての変更はファイルに直接保存されます — あなたのデータは、プレーンテキストとして

> **注意：** セクションの削除、リネーム、並べ替えは `dashboard.md` ファイルを直接編集して行います。ノートへの変更はダッシュボードビューに即座に反映されます。

## 新着情報

### 3.9.2
- **素材ライブラリの即時テーマ切替** — プラグインのテーマを切り替えると、素材ページがダッシュボードのボードと同じように、その場で即座に再テーマ化されるようになりました。閉じて開き直す必要はありません。カスタムカラー、背景画像、外観設定も素材ページに適用されるようになります
- **タイプフィルターを1つのドロップダウンに集約** — 画像/動画/テキストのフィルターが1つのドロップダウンボタンにまとまり、ツールバーがより静かになりました。ページネーションはフラットになり、すべての素材に直接アクセスできます
- **カード下部ベースストリップの新配色** — ポラロイドカードの下部メタストリップが厳選された色セットになり、ライト/ダーク両モードで共通になりました

### 3.9.1
- **素材ライブラリの 500 件上限を撤廃** — 以前は 1 回のレンダリングで 500 件までしか表示されず、それを超えた素材はページ移動できず、グループビューではフォルダごと失われていました。今後は：平らなビューではページネーションですべての素材に直接アクセスでき、グループビューでは各グループごとに段階的にレンダリング（最初の 50 枚 +「さらに表示」）。折りたたまれているグループは完全に構築しないため、超大規模な保管庫でも素材を失わず、一度に数万ノードをマウントすることもありません
- **フォルダグループへのドラッグ移動** — フォルダグループビューで素材カードを別のグループにドラッグすると、ファイルが移動されます。複数枚を選択して一緒にドラッグすれば一括移動でき、同名の競合は自動的にスキップして通知します。ターゲットグループにホバーすると「離して ×× に移動」と表示されます
- **グループの列レイアウトを修正** — 画像のアスペクト比の検出が完了すると、各グループのウォーターフォール列がすべて再配置されるようになりました（以前は最初のグループのみ再配置されていました）

### 3.9.0
- **完全な素材ライブラリ** — 左のリボンに square-sparkles アイコンが追加。開くと全ページの素材ライブラリが表示され、保管庫内の画像、動画、表紙付きノートがすべてウォーターフォールに集約されます
- **2 つのカードスタイル** — 元の表紙カード / Pin スタイルのポラロイドカードをワンクリックで切り替え。密度は 3 段階。フォルダ、タグ、タイプでグループ分けして閲覧でき、グループビューには左側のナビゲーションレールと一括折りたたみがあります
- **お気に入り** — カード上のハートをクリックして素材をお気に入り登録。ツールバーのハートボタンでお気に入りのみを表示できます
- **一括整理** — ドラッグで複数選択、右側のアイコン機能レールで一括タグ付け、移動、パスコピー、削除
- **エージェント連携** — 選択した素材をワンクリックで Agent スキルに送信。パスはプロンプトテンプレートに自動的に引き継がれます
- **ドラッグで即保存** — パソコンの任意の場所から画像/動画をドラッグすると、自動的に保管庫にコピーされ、グループごとの位置に配置されてタグ付けされます。デフォルトの保存場所は設定で変更できます

### 3.8.11
- **多言語インターフェースの拡充** — 日本語、韓国語、スペイン語、フランス語、ドイツ語、ブラジルポルトガル語、ロシア語、タイ語を新たに追加。簡体中国語、繁体中国語、英語と合わせて合計 11 言語のインターフェースに対応します。新規インストールでは Obsidian の言語をフォローでき、設定または言語選択リストから切り替えられます。翻訳はオフラインでパッケージに含まれます

- **習慣のカウントモード** — 習慣は繰り返しクリックで回数を累計するモードに切り替えられます。ウィジェットには当日のカウントが表示され、統計パネルでは累計データの確認とモードの切り替えが可能です
- **プロパティグループのリンクジャンプ** — フォルダセクションまたはデータベースセクションを双方向リンクプロパティでグループ化している場合、グループ名をクリックすると対象ノートが開きます
- **カウントダウンとウェブの修正** — カウントダウンの目標時刻選択の操作を修正。Google OAuth ログインは外部ブラウザに遷移して認証を続行します

### NetEase アカウントログインとプライバシー

デスクトップで、設定 → Apex Dashboard → ウィジェット → 音楽 を開き、「Phone / NetEase でログイン」を選択します。案内された場合は公式サイトで携帯電話によるログインを完了します。NetEase が QR ログインを要求する場合があります。このプラグインには個別の SMS エンドポイントはありません。会員資格、購入、地域権限は NetEase によって判定され、トライアルのクリップはフルトラックとして再生されません。

認証情報は NetEase に直接送信されます。プラグインはアカウントと再生 URL のリクエストにローカルセッションを使用します。Cookie は data.json や Vault 同期の外側にある、隔離されたローカルの Obsidian Electron セッション内に留まります。ログアウトすると再生が停止し、そのローカルセッションは消去されます。期限切れの場合は再ログインしてください。サードパーティのプロキシは使用していません。

### セクション間でのカード移動

Todo、メモ、付箋のセクション間でカードのヘッダーをドラッグできます。カバーの有無にかかわらずノートもこれらのセクションに移動できます。メモの移動先では、元のテキスト、タスク、リンクがメモとして表示されます。Todo の移動先では、既存のタスクが保持され、他の空でないテキスト行とノートリンクは未完了の項目に変換されます。付箋の移動先では、ノートにカバーがあるかどうかを含む、元のカードの見た目が保持されます。変更はリロード後も保持されます。ボードのカードを移動しても、リンクされた Vault のファイルは移動も削除もされません。

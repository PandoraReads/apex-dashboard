# 2026-11-01

## 新增布局 `immersive-light`（沉浸式浅色）

- **枚举**：`DashboardLayoutMode` 增加 `'immersive-light'`（src/types.ts）。
- **家族判定**：`src/immersive-grid.ts` 新增纯函数 `isImmersiveMode()` / `immersiveTone()`；
  所有布局分支（view/renderer/main/parser/sync/workspace-switcher）从
  `=== 'immersive'` 改为走 `isImmersiveMode()` 或 `renderer.isImmersiveLayout()`。
  手机端仍被 `effectiveLayout()` 钉在 `side`。
- **文件格式**：`KNOWN_LAYOUTS` 增加 `immersive-light`；`generateDefaultMarkdown()`
  在两种沉浸式色调下都产出同一套沉浸式模板，仅 `layout:` 值不同。
- **CSS**：沉浸式章节的 96 处 `[data-layout="immersive"]` 改为前缀匹配
  `[data-layout^="immersive"]`；硬编码暗色抽成 `--imm-*` 色调令牌（tile/scrim/pill/
  ghost 文本/resize 等），新增 `[data-layout="immersive-light"]` 令牌块（浅色玻璃 +
  深色文字 + `color-scheme: light`），位置必须在该章节里排在暗色块之后（同特异度靠源顺序取胜）。
- **i18n**：`settings.layoutImmersiveLight` 已补齐 11 种语言（verify-i18n 要求键集完全一致）。
- **验证**：新增 `scripts/verify-immersive-light.ts` + `npm run test:immersive-light`。
  全量 90+ 验证脚本中仅 `test:library-card-size` / `test:material` / `test:material-render`
  失败 —— 已用 git stash 确认这三个在改动前就失败（与本次无关）。
- **踩坑**：用 Edge headless 做视觉核对时，`.dashboard-imm-bg-scrim` 必须是
  `.dashboard-imm-bg` 的**子元素**；放成兄弟节点会盖住整屏文字（浅色下时钟直接糊掉）。
  另外 `getComputedStyle` 在 `background` 带 transition 的元素上会读到过渡中间值，别据此判断。

## 打包发布（3.9.3）

- 构建：`npm run build`（tsc 无错 + esbuild production），产物 `main.js` ≈ 4.8MB / 2316 行，
  `styles.css` ≈ 887KB。插件运行只需 `main.js` + `manifest.json` + `styles.css` 三件。
- 发布目录：`release/3.9.3/apex-dashboard/`；压缩包 `release/apex-dashboard-3.9.3.zip`
  （顶层为 `apex-dashboard/`，解压即得插件目录）。
- **zip 制作用 Windows 自带 `tar.exe -a -c -f`**，不要用 `Compress-Archive`：后者写出的条目
  路径是反斜杠（`apex-dashboard\main.js`），在 macOS/Linux 的解压工具里会变成一个怪异文件名。
  PowerShell 里 `Add-Type` 被安全策略禁用，所以校验只能靠 bash 的 `unzip -l`。
- 已安装到本机测试库 `E:\Documents\Obsidian\.obsidian\plugins\apex-dashboard\`（之前未安装，
  新建目录，未改 `community-plugins.json`，需在 Obsidian 设置里手动启用）。
- **版本号注意**：`manifest.json` 已是 3.9.3 且 `versions.json` 里也有 3.9.3 条目，
  但 `package.json` 仍是 3.9.2。带 immersive-light 的发版建议升到 3.10.0 并手改三处
  （manifest / package / versions），仓库里没有 `version-bump.mjs`，`npm run version` 会失败。

## 新增布局 `immersive-light`（沉浸式浅色）

- **枚举**：`DashboardLayoutMode` 增加 `'immersive-light'`（src/types.ts）。
- **家族判定**：`src/immersive-grid.ts` 新增纯函数 `isImmersiveMode()` / `immersiveTone()`；
  所有布局分支（view/renderer/main/parser/sync/workspace-switcher）从
  `=== 'immersive'` 改为走 `isImmersiveMode()` 或 `renderer.isImmersiveLayout()`。
  手机端仍被 `effectiveLayout()` 钉在 `side`。
- **文件格式**：`KNOWN_LAYOUTS` 增加 `immersive-light`；`generateDefaultMarkdown()`
  在两种沉浸式色调下都产出同一套沉浸式模板，仅 `layout:` 值不同。
- **CSS**：沉浸式章节的 96 处 `[data-layout="immersive"]` 改为前缀匹配
  `[data-layout^="immersive"]`；硬编码暗色抽成 `--imm-*` 色调令牌（tile/scrim/pill/
  ghost 文本/resize 等），新增 `[data-layout="immersive-light"]` 令牌块（浅色玻璃 +
  深色文字 + `color-scheme: light`），位置必须在该章节里排在暗色块之后（同特异度靠源顺序取胜）。
- **i18n**：`settings.layoutImmersiveLight` 已补齐 11 种语言（verify-i18n 要求键集完全一致）。
- **验证**：新增 `scripts/verify-immersive-light.ts` + `npm run test:immersive-light`。
  全量 90+ 验证脚本中仅 `test:library-card-size` / `test:material` / `test:material-render`
  失败 —— 已用 git stash 确认这三个在改动前就失败（与本次无关）。
- **踩坑**：用 Edge headless 做视觉核对时，`.dashboard-imm-bg-scrim` 必须是
  `.dashboard-imm-bg` 的**子元素**；放成兄弟节点会盖住整屏文字（浅色下时钟直接糊掉）。
  另外 `getComputedStyle` 在 `background` 带 transition 的元素上会读到过渡中间值，别据此判断。

## 二次迭代：整块覆盖 → 按条目合并（用户要求）

- 用户明确要 **合并** 而不是整块替换：同条目更新、卡片新条目追加、日记里多出的条目不动。
- `daily-note-block.ts` 改为 `mergeDailyTasksBlock(md, heading, tasks)` →
  `{ content, replaced, updated, appended }`；按**任务纯文本**匹配（去 checkbox/缩进/` ⏰ reminder`
  后 trim 相等，首个出现优先）。匹配行重写为卡片当前状态（勾选/提醒/缩进）；
  非任务行（手写文字、`####` 子标题、空白）原样保留；`replaceDailyBlock` 已删除。
- 结构限制（写在函数注释里）：已匹配父任务新加的子任务只能**追加在块尾**，无法塞回
  父级下（避免重排用户手工整理过的行）。
- 首次保存（无标题块）仍走 `prependAfterFrontmatter`；幂等（合并两次字节一致）。
- 测试脚本同步重写：更新/追加/保留三类断言 + 手动勾选以卡片为准 + 边界/幂等/CRLF/特殊字符。
- TaskItem 没有 `id` 字段（text/checked/reminder/children/collapsed），测试造数别想当然。

  （Obsidian 测试库 + texousliu），发布后两处都要 cp。
- **顺带加固**：旧代码在日记里已堆了重复块（4×快速上手 + 2×备忘录）。
  `mergeDailyTasksBlock` 现在会**自动清理同名重复块**（第一块合并，其余整节删除，

  避免每次保存多一个空行、删块后留空行垃圾（测试 5c 抓到了这两个回归）。
- 提醒用户：重载插件（Ctrl+R 或开关一次插件）后保存一次即自愈。

## 样式微调：添加任务输入框聚焦态

- `.dashboard-task-input`（任务卡与项目卡共用的内联加行输入框）原为
  `border: none !important` 的纯下划线式输入框，聚焦只变文字色。
- 改为聚焦时：placeholder 隐藏（`::placeholder { color: transparent }`）+
  显示强调色下划线（`border-bottom ... !important`，需同级别 !important 才
  压得住上面的 none）。styles.css 是静态文件不进 bundle，改完直接 cp 到
  发布目录和两个库即可，无需重新 build main.js。
- **二次修正（闪烁）**：聚焦才创建的边框首帧取 `currentColor`（深色）再过渡到
  强调色 → 黑→主题色闪烁，且高度跳 1px。改为基态常驻
  `border-bottom: 1px solid transparent !important`（放在 `border: none` 之后，
  同块内后者覆盖前者），聚焦只改 `border-bottom-color`。经验：给无边框输入框
  加聚焦线时，用透明占位而不是聚焦时新建边框。

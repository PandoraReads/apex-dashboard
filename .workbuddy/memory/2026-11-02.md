## 修复：沉浸式工作台从笔记返回后卡片无法拖动

- 症状：工作台点笔记跳转 → 回到工作台 → 卡片不能拖；必须点「锁定布局」再点「编辑布局」才恢复。
- 根因：两条就地刷新路径（`refreshSectionInPlace` 和 vault 批量 `refreshSectionsFor`）会清空 `dndCleanupFns` 以移除被换出 tile 的卡片级 DnD 监听，但该数组同时携带 `setupImmersiveDnD` / `setupImmersiveTileMenu` 的清理函数——它们把整卡拖拽/右键菜单绑定在**幸存的网格**上。清空后没有任何路径重新绑定：看板外观正常但 tile 拖拽失效。新增笔记触发 vault create/modify → debounce → flushVaultRefresh → 有扫描分区刷新（swapped>0）→ 监听被抹掉；用户切回工作台即中招。锁定/编辑按钮之所以能修，是因为它走 sync→notifyCallbacks→full render 重建了整个网格。
- 修复：
  - `view.ts` 新增 `rewireImmersiveGridDnD(kanban)`（重跑 setupImmersiveDnD + setupImmersiveTileMenu），并在两处 wipe 点之后调用。

## 修：日历卡片加了任务不刷新（agenda 弹窗添加后）

- 根因：当天没有日记时 `insertTaskForDay` 第 3 步写入**看板文件本身**；而 view 的 vault 事件 `record()` 刻意跳过 dashboard 路径（`if (file.path !== dashboardPath)`，"引擎自己管"），于是 `vaultChangePaths` 为空 → `changedMd=false` → `refreshSidebarCalendarNow()` / `refreshCalendarSections()` 都不触发。侧栏 widget DOM 在整页重渲染中被保留，所以连 full render 也不重扫 → 网格与 agenda（用渲染时的 byDay 快照）一直陈到切换视图（视图切换走 load() 全量重扫）。
- 修复：`calendar-modal.ts` 新增 `requestCalendarRefresh(targetPath?)`（invalidatePath + 在 `.apex-dashboard-root` 上派发冒泡 CustomEvent `dashboard-calendar-refresh`）；DayAgendaModal.addTask 成功后调用，两个 modal 的 toggle 也调用（同一盲区）。`view.ts` 在 onOpen 里给 **containerEl**（稳定宿主，不在每次 render 重建）注册监听 → `refreshSidebarCalendarNow()` + `refreshCalendarSections(containerEl)`。选择 CustomEvent 而非直接 import，避免 calendar-modal ↔ calendar-widget/calendar-section 循环依赖。
- 测试：`scripts/verify-calendar-add-refresh.ts`（npm run test:calendar-add-refresh）断言两端接线 + record() 跳过 dashboard 的前提仍在。
- 产物已同步 release/3.9.5 + 两库 + zip。

## 再修：日历加任务仍不刷新（真因）+ 投放顺序设为配置项

- 用户反馈上一版修复无效（重载后依旧不刷新），且任务都落在今日日记里。
- 真因两处（上一版只补了「事件」这一半）：
  1. **刷新只靠广播事件**：`requestCalendarRefresh` 用 `activeDocument.querySelector('.apex-dashboard-root')` 找根节点，命中的可能是别的 leaf / material view 的根 → 事件根本没到打开日历的那个视图。
  2. **重扫读到旧内容**：`collectVaultTasks` 有两层快捷路径会在刚写完的瞬间失真——metadata `listItems` 预过滤（Obsidian 异步重建索引，刚加任务的笔记还像"没有任务"）与 `vault.cachedRead`（可能仍是写前快照）。所以 rescan 跑了却扫不到 → 与"切到别的视图（走 load 全量）才刷新"完全吻合。
- 修复：
  - `calendar-modal.ts`：CalendarModalCallbacks 新增 `onTaskWritten?()`，DayAgendaModal 在 add 成功后直接调用（DOM 无关，必有到达），并 `setTimeout` 400ms 再补一次（等 vault 索引追上，尤其新建日记的场合）。
  - `calendar-widget.ts` / `calendar-section.ts`：把 `onTaskWritten` 接到自己的 reload（widget → render()，section → 抽出的 `reloadInPlace()`，也继续给 sectionReloaders 用），并透传给 CalendarMonthModal。
  - `alltasks-scan.ts`：新增 `freshReadPaths`，`invalidatePath` 同时登记；扫描时命中该路径则**跳过 metadata 预过滤 + 用 `vault.read`（磁盘）**而非 cachedRead，一次性失效。
- 新配置项「任务投放顺序」`settings.calendarTaskFallback: 'auto' | 'day' | 'today' | 'dashboard'`（默认 auto 保持历史行为；选了固定目标 calendarTaskTarget 时不生效）：
  - `insertTaskForDay` 新增第 7 参 fallback：day 只写当日日记（缺则新建，不再回落到今日/看板）；today 只写今日日记（缺则新建今日）；dashboard 直接写看板清单；auto 原链路。
  - `settings.ts` 加下拉；11 语言 key：settings.calendarTaskFallback / Desc / Auto / Day / Today / Dashboard。
- 测试：新增 `scripts/verify-task-scan-freshness.ts`（stale cachedRead + 滞后 metadata 下，invalidatePath 后必须走磁盘并拿到新任务）；`verify-calendar-task-insert` 扩到 27 scenario（21-26 覆盖四种 fallback + 非法值，27 校验设置默认/下拉/接线/多语言）；`verify-calendar-add-refresh` 加 onTaskWritten 接线断言。
